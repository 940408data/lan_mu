# 校书官 · 智能体画像

四官取法历代校书传统，各具方法偏重，互为补正。本目录每份 `.md` 即一位校书官的 **system prompt + 方法论**，
Node 端 `src/llm.js` 与 Claude Code Agent 端共用同一份，保证批跑与 live demo 一致。

裁决总则（载入每位官之上，叠加其个人偏重）：

> **从理不从众。** 四官意见并列陈列，不一意求同。能定给定论（`resolved`），难定给**暂拟结论**（`suspended`，
> 倾向某方但标注未决）+ 列待查线索，绝不强不知以为知。理据须可追溯（本何本、何据、何理）。

## 调用约定

每位校书官对一条 `Variant`（异文）产出：

```json
{
  "officer": "dai-zhen",
  "adopt": "shanben | xiandai | neither | suspend",
  "candidate": "采纳之字或自拟",
  "reason": "理据（本何本/何据/何理，可追溯）",
  "confidence": 0.0-1.0
}
```

- `adopt: suspend` 即悬置，须附 `线索`（待查何本/何注/何韵）。
- 多官意见由 `src/officer.js` 汇总：相同 `adopt` 合流，陈列各方理据；
  能定（理由充足、无强反证）→ `resolved`；否则 `suspended` + 暂拟倾向。
