# 古籍校勘推广指南

> 把《大学章句》已走通的 AI 校勘管线推广到《中庸章句》及更多古籍（论语/孟子等）的操作手册。
> 方法论见 `docs/古籍校勘实施实录.md`；可复用 skill 见 `.claude/skills/guji-jiaokan/SKILL.md`。

## 0. 适用范围

任意"有公开善本扫描 + 现代点校本"的古籍。**每本书版面结构不同，必须先版面抽样（layoutProbe）总结该书网格与经注规则，才能进行后续。**

## 1. 推广前置

1. **版本登记** `collation/config/editions.yaml`：加该书条目（善本 A 级公开 / 现代本 B 级自用，ocrDir/pdfDir）。
2. **视觉配置** `collation/config/vision.yaml`：初校/覆校底层模型、思考开关、阈值。key 设 env `DASHSCOPE_API_KEY`（脚本自读，勿写入仓库）。
3. **数据落位** `input_data/<书名>/{善本,现代本}_ocr|_pdf/`（gitignored，运行期读取）。

## 2. 标准流程（按里程碑）

```bash
# ── M0 版面结构抽样（每书必做，确认该书网格与经注规则）──
# 用 layoutProbe 抽样 3-5 页，得到 列×行、每格字数、顶格/退格规则

# ── M2 视觉重OCR + 互证 + 干净底本 ──
node collation/tools/recollate.js <书名> --pages=1-N --conc=3      # 视觉重OCR+互证
node collation/tools/build-v2.js <书名> --in=recollate-1-N.json   # 规则仲裁→干净底本（原刻字形）
node collation/tools/verify-v2.js <书名> --conc=3                 # 覆校真疑难→shanben-v2-final
node collation/tools/build-v2.js <书名> --in=recollate-1-N.json   # 重跑应用覆校结果

# ── M3 版面判定经注（用 M0 抽样的网格参数 --cols/--rows）──
node collation/tools/judge-grid.js <书名> --pages=<正文起>-<正文止> --conc=3 --cols=16 --rows=15
node collation/tools/verify-jz.js <workId> --jz=collation/data/<书名>/grid.json   # 兰木结构核验准确率

# ── M4 对校 + 全量校书官 + 双本出具 ──
node collation/run.js <书名>          # diff（干净底本）+ 校书官（4官并行增量保存）+ 双本

# ── M6 进兰木引擎（善本底独立新作品，不动通行本）──
node collation/tools/build-works.js <书名> <新作品id> --base=<模板作品>
npm run build -- --work=<新作品id> --only=html     # 验证
```

**M5 人工终裁**（归人）：对 suspended 异文核他本/石经，结论回写 `verdicts.json` 的 `human` 字段，重跑 `run.js <书名> --step=export` 吸收。

## 3. 中庸章句实操

- **页数**：善本 78 页（约为大学 2 倍）。先 `layoutProbe` 抽样（如 page 8/30/50）确认中庸网格——**可能不同于大学 16×15**，以抽样为准。
- **章节锚点**：中庸分 33 章，强锚 `右第X章`（align.js 已含此正则）。
- **序**：中庸章句序（page 前几页）另成卷（zhongyongxu-songben），正文（page 7/8 起）进 zhongyong-songben。
- **书末题跋页**：视觉识别差，宜人工。
- 进引擎：`node collation/tools/build-works.js 中庸章句 zhongyong-songben --base=zhongyong`。

## 4. 其他古籍（论语/孟子大部头）注意

- **体量大**（论语善本 445 页、孟子 547 页）：务必并行 + 多 key 轮询 + **断点续传**（recollate/judge-grid/adjudicate 均支持）。
- **版面抽样先行**：论语/孟子集注的半叶行款、经注格式可能与大学/中庸不同，**先 layoutProbe 确认再定网格参数**。
- **分卷册处理**：按 works/lunyuN、mengziN 的卷册边界分批跑，避免单次过长。
- **成本闸**：大跑前用小样本（几页）验证质量与一致性，再全量。

## 5. 每书 Checklist

- [ ] editions.yaml 登记（善本 A 公开 / 现代本 B 自用）
- [ ] layoutProbe 抽样得版面结构（列×行、顶格/退格规则）→ 记录
- [ ] recollate 视觉重 OCR + 互证（一致率应 ≥90%，低则查版面/OCR 质量）
- [ ] build-v2 干净底本（存善本原刻字形）→ verify-v2 覆校真疑难 → 重跑应用
- [ ] judge-grid 经注判定（用该书网格参数）→ verify-jz 核验（≥90% 为佳）
- [ ] run.js 全量：对校 + 校书官 + 双本
- [ ] 人工终裁悬置项（核他本/石经）→ 回写 → 重出
- [ ] build-works 进引擎 + `build --only=html` 验证
- [ ] 善本点校本公开 / 现代本自用（不入 dist）

## 6. 常见问题

| 问题 | 处理 |
|---|---|
| 视觉判定经注准确率低 | 检查是否走了版面结构先行；提高 dpi；确认网格参数对；覆校复判 |
| 视觉重 OCR 漏字 | 正常（关思考漏字），互证时缺字采旧 OCR |
| 书末题跋页识别差 | 人工处理，不强求视觉 |
| 校书官太慢 | 用 qwen3.7-plus（初校）；确认 adjudicate 增量保存+并行生效 |
| bash 报分类器超时 | key 已由脚本自读 ~/.bashrc（resolveApiKey），勿在命令内嵌 key |
| 善本某页 fetch failed | 网络抖动，judge-grid/recollate 断点续传重跑该页即可 |
