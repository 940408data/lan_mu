# 校勘流水线清洗优先方案

> 状态：方案评审中（首版）
>
> 分支：`engine/collation-cleanup-first`
>
> 范围：`collation/` 的双本校勘链路。先解决输入的版面污染、阅读顺序和资料隔离；不在本方案内重做古籍 OCR 模型。

## 结论

「对校前先清洗两本」应成为流水线的硬前置条件，但这里的清洗不能等同于删除字符。正确做法是：

1. 保留不可变原始 OCR；
2. 由版面与规则建立可追溯的正文流、校记流、页眉流等结构；
3. 只让正文流进入对齐、异文、句读和定本；
4. 把每一处排除留在审计记录，低置信项交人工确认；
5. 公开与自用数据在文件层面隔离。

这会消除绝大多数「假夺衍」「页眉入正文」「校记参与异文」问题，并使后续视觉核验只面对真实疑难，而非替清洗兜底。

## 现状复盘

### 已有能力

- 善本已有双路 OCR 互证与 `shanben-v2.json` 回修通路；`build-v2.js` 能保留善本原刻字形，`verify-v2.js` 能将视觉复核结果回填。
- 对齐前已有现代本句末切分、少数脚注/校记剥离、异体归一和章节锚点。
- P4.5 可把一部分页眉、牌记、现代校记归为噪声，且保留核验记录。
- 系统已经有人工精校台和人工裁定回灌入口。

### 根因与风险

| 优先级 | 发现 | 根因 | 后果 |
|---|---|---|---|
| P0 | 清洗发生在 `align.js` 的临时字符串中，而 P6 现代本直接输出原 OCR | 没有正式的清洗产物与唯一正文源 | 对齐虽过滤，最终文本仍有「大／學」、脚注、页眉和 LaTex 标记 |
| P0 | 书题识别仅支持单行且含「章句／集注」的少量模式 | 处理单位是单行字符串，未建页面区域与阅读顺序 | 分行书题、鱼尾、页码和版心残字进入正文并制造假夺衍 |
| P0 | 校记识别依赖宽泛正则 | 正文、注释、脚注和校记没有类型边界 | 可误删正文或打断引号；被剥内容也没有与脚注标记建立关联 |
| P0 | `shanben-v2.json` 仍是每页扁平文字 | OCR 过程已丢失坐标、列、区域类别和经注关系 | 无法可靠排除封面、牌记、版心，也不能解释清洗决定 |
| P1 | P4.5 才把噪声分类 | 噪声在对齐和 diff 后才被发现 | 先污染对齐游标、簇和校书官输入，成本高且难完全回收 |
| P1 | P6 将裁定夹注写进善本正文，将悬置意见拼进现代全文 | 正文、校记、工作日志没有分层 | 读者拿到的不是稳定正文；一次重跑会改变阅读文本 |
| P1 | B 级现代本的正文及长片段目前会进入可入库的中间/输出目录 | 资料分流只在说明中，没有在路径和序列化层强制 | 存在现代整理本内容及其派生结果被误提交或对外暴露的风险 |
| P2 | 缺少清洗单元测试、语料级质量闸和双跑差异报告 | 没有可验收的中间层契约 | 清洗规则调整可能静默丢正文或重新引入噪声 |

## 目标架构

原链路：

```text
原 OCR → 对齐时临时删文本 → 对校 → 出具时重新读取原 OCR
```

调整为：

```text
原始 OCR（只读）
  → P1.5 版面/文本清洗（可审计、可复跑）
  → clean body / apparatus / paratext / review 三条数据流
  → P3 对齐（仅 body） → P4–P5 校勘 → P6 分层出具
```

### 清洗后的页面模型

每页不再只有 `lines: string[]`，而应得到以下可序列化结构。初期没有 bbox 时允许以行号作为降级定位；新 OCR 必须保留 bbox 与置信度。

```json
{
  "page": 7,
  "sourceHash": "…",
  "regions": [
    {
      "id": "p7-r03",
      "kind": "body",
      "text": "……",
      "readingOrder": 3,
      "source": {"lines": [4, 5], "bbox": null},
      "confidence": 0.98,
      "rule": "body-continuation"
    }
  ],
  "excluded": [
    {
      "kind": "running_head",
      "text": "大學",
      "source": {"lines": [11, 12]},
      "rule": "repeated-title+isolated-lines",
      "confidence": 0.99
    }
  ]
}
```

区域类别固定为：`body`、`section_heading`、`annotation`、`footnote`、`collation_note`、`running_head`、`page_number`、`colophon`、`cover`、`unknown`。正文流由 `body + section_heading + annotation` 按阅读顺序组成；其他类别均不进入对校正文。

### 双本分别清洗，规则共享但不混同

| 项目 | 善本 | 现代本 |
|---|---|---|
| 重点 | 封面、书题、版心、鱼尾、牌记、经注阅读顺序 | 页眉、页码、脚注、校记、公式/上标残留、跨栏断行 |
| 正文保留 | 善本实印字形；异体只在对齐键归一 | 原整理本字形与标点；绝不因清洗擅改文字 |
| 复杂版面 | 用网格/列序、版面规则与 VLM 低置信复核 | 用段落/脚注/页眉模式与版面位置；不以句意猜删 |
| 输出权限 | 可生成公开的清洗底本与点校本 | 仅生成本地自用清洗稿，不能写入公开目录 |

## 实施方案

### 第一期：建立独立清洗层（本次功能的最小可用范围）

1. 新增 `collation/src/cleanup.js`，输入 `Edition`，输出页面区域模型与正文流；禁止在 `align.js` 内再做不可见的删除。
2. 新增 `collation/tools/clean.js <书名> [--edition=…]`，支持 `--dry-run`、`--report` 与按页复核。
3. 规则按由强到弱的顺序执行：
   - 精确识别封面、页码、重复书题、单字/分行书题；
   - 识别行首脚注和正文内上标，建立引用与脚注的关联；
   - 识别明确的校勘体例，移入 `collation_note`，而非删除；
   - 处理 OCR 标记残留（如 `$^{①}$`）并记录原文；
   - 仅在跨页前后文、位置和重复模式都满足时合并断行；不以语言模型补字。
4. 对无法高置信分类的区域标为 `unknown`，保留在待审队列；不得默认丢弃。
5. `align.js` 改为只读取清洗正文流，并携带 `regionId`/页码溯源。

### 第二期：让出具与审计使用同一数据源

1. `buildXiandaiText()` 改读现代本清洗正文流，不得再按页拼接 raw OCR。
2. 善本点校以清洗后的善本正文流加句读；P5 的句读应保存为结构化 `punctuated.json`，而不是只在 Markdown 拼接。
3. 正文、校勘记和模型工作日志拆分：
   - 正文：不含“采善本”“按”“悬置意见”等流程标记；
   - 校勘记：只含人工确认或有可核证来源的结论；
   - 机器意见：进入内部 review 数据，不作为定论输出。
4. 引入 `textStatus: draft | reviewed | published`。有 `unknown`、低置信清洗项、未审夺衍或未闭合引文时，不得标为 `published`。

### 第三期：资料隔离和可验收性

1. B 级现代本及其含连续正文的派生物统一写入受忽略的私有根目录（推荐 `input_data/<书名>/_derived/`）；公开 `collation/data/` 只保留善本产物、统计和不含现代本连续文本的摘要。
2. 中间引用使用 `page + regionId + hash + 范围`，代替在公开 JSON 中复制现代本长句。
3. 加入纯合成测试夹具，覆盖：分行书题、重复页眉、脚注标记、内联校记、跨页续文、真正标题、真正短句、无标点善本。
4. 加入质量闸：
   - 正文中不允许出现已识别页眉、LaTex 上标残留、孤立书名单字；
   - 每一条排除记录均有来源、规则和置信度；
   - `unknown` 数、正文字符数变化、对齐 orphan/簇数均输出与基线的差异报告；
   - 任意正文删除需人工确认或满足可解释的高置信规则；
   - 同一输入重复运行得到字节稳定结果。

### 第四期：再做学术校勘与版面转写

清洗质量闸通过后，重新执行「对齐 → 簇核验 → 校书官 → 人工终裁」。经注分栏继续以当前 grid-first 路径为主，但其输入必须来自已清洗且带阅读顺序的数据，而非扁平 OCR 串。

## 迁移与验证顺序

1. 以《大学章句》建立清洗前/后双跑，不覆盖既有产物。
2. 人工抽查：每页至少检查一处正文、页眉/书题、脚注/校记；高风险页（章首、跨页、题跋）全查。
3. 比较清洗前后：正文字符数、被排除区块数、orphan 数、夺衍簇数、真异文数及抽样可读性。
4. 清洗报告经人工确认后，才切换 `align` 默认输入；保留旧路径一个版本周期供回退和差异诊断。
5. 先迁《大学章句》，稳定后用同一合成测试和参数框架迁《中庸章句》；书种特有规则写入配置，禁止把《大学》页码硬编码为通用逻辑。

## 验收标准

- 《大学章句》现代本正文不再出现单列「大／學」、重复「大學章句序」、`$^{①}$`、行首脚注或校书官工作日志。
- 善本正文不再含封面/书题/牌记；所有保留与排除均能回指到页和行（后续为 bbox）。
- 真实校记仍完整可查，且不会以正文形式参与对齐。
- 清洗后再对校的假夺衍显著下降；具体阈值在首次双跑后以可复现基线确定，不能预先用主观数字掩盖正文误删风险。
- B 级现代本及其连续派生文本不进入公开目录或提交物。

## 暂不采用的做法

- 不在 diff 后继续靠“页眉黑名单”消噪：它已污染上游对齐。
- 不让 LLM 仅凭文义决定删哪行：模型只可协助低置信版面判定，原图与人工复核仍是证据。
- 不把清洗理解为繁简转换或异体归一：这些是对齐键策略，不能改变底本文字。
- 不以输出 Markdown 作为唯一中间态：必须先有结构化、可审计数据。
