# 网格基通用性验证 · 论语集注

> 状态：2026-08-18 方案（待执行）。目标：以《论语集注》第一卷为材料，完整跑通 G 管线 G1→G5，验证网格基方法论在「非章句体例大部头」上的通用性；沉淀通用 skill，供后续 9 卷 + 序说复跑。
>
> 关联：[校勘双管线对比](校勘双管线对比.md)（§4 通用性待办）、[网格基精校台启动指南](网格基精校台启动指南.md)（T8 其他书推广）、[网格基重构-双书实施验收](网格基重构-双书实施验收与量化评价.md)（双书基线）。

## 1. 背景与目标

G 管线（网格基五阶段）已在大学章句 / 中庸章句双书验收（一致率 99.6/98.9%、sections 12/34 全对、量化 8.8 分），但四个通用性命题未证（[双管线对比 §4](校勘双管线对比.md)）：

1. 异文归类覆盖（sub/extra/missing 之外的完整归类靠 officer 隐式）
2. 四校书官在非朱熹章句体例上的适用性
3. VARIANT_MAP 异体归一与 fuzzy 兜底在大部头上的压测
4. G5 出口边界（跨页切片、title/○ 处理）在其他版面上的健壮性

**本次验证回答**：换一部体例不同（集注体、以篇分节、注文占比过半）、规模不同（全书 445 页 vs 双书 35/75 页）的书，G 管线能否不改方法论、只做登记式适配就跑通全流程。底本与大学/中庸同源（影像实拍核验：宋本刻本体系、整叶两半叶，PDF 元数据同批 MuPDF 产出），无换底问题。

**成功判据（总）**：第一卷 G1→G5 全链产物齐备、各项质量闸达标（§8），且适配改动不破坏双书回归；通用 skill 落盘后第二卷可按 skill 复跑。

## 3. 差异断点分析（论语 vs 双书）

调研已确认以下 8 个断点，按影响排序：

| # | 断点 | 双书现状 | 论语实况 | 对策（落点） |
|---|---|---|---|---|
| 1 | **底本版面规格** | 宋刻原刊，16 列×15 行（layout.json 在册） | 影像与大学同源同形态（2026-08-18 实拍核验：p10/p267 均黄纸墨字刻本、整叶两半叶，无四库页眉）；每卷有「宋本論語集注卷X」扉页；论语卷行列规格待实测确认 | S0 `layoutProbe` 抽样实测落 layout.json（常规确认，非决策点） |
| 2 | **目录结构** | `input_data/<书>/{ocr,pdf}/` 平铺 | `input_data/论语集注/<卷>/{ocr,pdf}/` 分卷 | S1 装载层支持卷目录映射（页码全局连续，可自动扫描生成） |
| 3 | **shanben-v2.json 依赖** | 旧管线 M2 生成（recollate→build-v2→verify-v2，重） | 无 | S1 新增轻量构造：从当涂_ocr md 直接拼 `pages[{n,text}]`，G1 指纹 + G2a 参校两用 |
| 4 | **章节锚规则** | `右X章` 收束式（CHAPTER_RE 硬编码于 src/grid.js）；序尾锚「淳熙己酉…朱熹序」 | **无右X章**；按**篇题开节**（學而第一 / 爲政第二…顶格大字）；序说无此二锚 | S1 锚规则参数化（per-work 登记），新增篇题开节式 sections 逻辑 |
| 5 | **OCR 幻觉噪声 / 扉页 / 非标准页** | 版心鱼尾书题，textPages/colophonFrom 登记 | 当涂 OCR 存在幻觉插入（实证 2 处：「欽定四庫全書」p10 首行、p267 正文中间——影像实拍均无此字样；全书 443/445 页无）；每卷「宋本論語集注卷X」扉页 | lite 构造剥已知幻觉行；幻觉属 G 管线 extra 类自然捕捉对象，不回修 OCR 源 |
| 6 | **四官底本名硬编码** | src/officer.js prompt 写死「当涂郡斋刊递修本，南宋」 | 硬编码不可移植，换书即失实 | S1 从 editions.yaml title 参数化 |
| 7 | **works 登记 / id 冲突** | 大学/中庸 songben 系列 | `lunyu1-10` 已被 CHM 现代排印本占用 | 新 id 规约 `lunyu-songben-vol1`（参照 daxue-songben-g5） |
| 8 | **儒藏本预清洗规则** | precleanModern 剥 LaTeX 脚注 / 页眉 / 校记（「司禮監本\|監本\|吳本」） | 论语儒藏本脚注用语未考察（样例未见 ① 序号） | S0 抽样考察，必要时扩充规则 |

已确认**无断点**（天然兼容）项：grid-review.js 网格规格自适应（从基础层实测取 cols/rows，CSS 默认 16×15 仅兜底）；四官聚合规则（证据分级+β+悬置三规则）与方法论无关书体例；G2b 儒藏本按目录全量读取——分卷目录下「第一卷/儒藏本_ocr」恰好只含本卷 19 页，天然契合分卷验证。

## 4. 总体策略

**先适配、后跑通、再沉淀、后推广**：

```
S0 环境与材料考察 ──► S1 登记式适配改造 ──► S2 G1 逐格转写 ──► S3 G2/G3 overlay
                                                        │
S7 后续卷按 skill 复跑 ◄── S6 通用 skill 沉淀 ◄── S5 G5 出口与验收 ◄── S4 G4 四官+精校台
```

原则：
- **登记式适配**：能进 editions.yaml / layout.json / 锚规则登记的，不写 if-else 分支代码；双书零行为变化（S1 末回归闸）。
- **新管线不回旧管线**：不跑 recollate/build-v2/verify-v2（那是 M2 重轨道）；底本参校用现成当涂_ocr md 的 lite 构造——这本身即是「G 管线脱离旧管线独立跑新书」的验证。
- **成本闸**：G1 先 3 页试跑看质量再全量；四官先 mock 全量、真实 LLM 视预算抽样。

## 5. 实施步骤

### S0 环境与材料考察（约 0.5 天）

1. **渲染环境修复**（阻塞项）：实测 sandbox 中 `pdftoppm` 缺失、playwright chromium 未装（`renderPage` 两路均失败）。任选其一：安装 poppler（pdftoppm）或 `npx playwright install chromium`。修复后渲染 1 页大学 PDF 回归对照。
2. **版面探测（M0，每书必做）**：抽 4 页（卷首 p10、正文 p12/p30、卷末 p49）跑 `layoutProbe` → 落 `collation/data/论语集注/layout.json`（cols×rows、双行小字、经注起格、版心书题）。**若版面非 16×15，本方案 S2 起的网格规格一律以 layout.json 为准。**
3. **底本核对（已完成，2026-08-18）**：浏览器实拍 p10 / p267 影像——宋本刻本体系、整叶两半叶、无四库页眉；OCR 中 2 处「欽定四庫全書」确认为 **LLM OCR 幻觉插入**（p267 影像正文连续无此词，p10 页顶亦无）。底本身份维持 editions.yaml 登记不变；版面行列以 layoutProbe 实测为准。
4. **页范围登记**：确认第一卷有效正文页（预计 p10-49；p50 卷二扉页）；序说页范围（p1-9，含总扉页 p1）；写入 layout.json（textPages / colophonFrom 同款字段）。
5. **儒藏本脚注考察**：抽 p5/p10/p23 看脚注形态（① 序号、〔…本作…〕行内注、校记用语），预判 precleanModern 覆盖度，缺则记入 S1 改造清单。
6. **产物**：layout.json、底本核验结论（已完成）、S1 改造清单终版。

### S1 登记式适配改造（约 1-2 天）

1. **卷目录装载**：新增卷映射解析（扫描 `input_data/论语集注/*/当涂郡本_ocr` 的页码范围自动生成 `<卷> → [起页,止页]` 映射，或 editions.yaml 内嵌 `volumes` 字段）。落点：`io.js`（listPages 支持卷路由）+ `grid-transcribe.js`（pdfDir 按页码路由到卷目录）+ `grid.js`（mdir 同理）。
2. **shanben-v2 lite 构造器**：新工具 `collation/tools/build-v2-lite.js <书> [--vol=第一卷]`——读当涂_ocr md，剥扉页行与已知幻觉行（如「欽定四庫全書」），拼 `pages[{n,text}]`，schema 与 shanben-v2.json 完全一致（loadM2Base 无感知）。
3. **锚规则参数化**：`src/grid.js` 的 CHAPTER_RE / PREFACE_END_RE 从 editions.yaml `structure` 派生（每书登记锚型：`右X章收束式` / `篇题开节式` / 自定义正则）；新增篇题开节式 sections 逻辑（篇题锚开节、锚块归 title，尾节至卷末）。论语卷一登记：`學而第一`、`爲政第二`。
4. **四官底本参数化**：`src/officer.js` prompt 底本描述改读 editions.yaml。
5. **works 登记**：editions.yaml 新增论语集注（structure: 序说 + 卷一[學而第一, 爲政第二] + …）；产出入库 id 定 `lunyu-songben-vol1`。
6. **回归闸（必过）**：大学/中庸 `grid-overlay.js` dry-run 输出与改造前逐项一致（一致率、sections 数、j/z 对照比例不变）；`test/` 既有用例通过。
