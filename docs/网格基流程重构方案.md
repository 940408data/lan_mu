# 网格基流程重构方案：视觉逐格为唯一基础层

> 分支：`engine/collation-grid-base`（worktree `.claude/worktrees/collation-grid-base`）
> 日期：2026-08-17。状态：方案（已经大学/中庸双书数据实证，未实施）。
> 探索工具：`collation/tools/explore-grid-align.js`（只读，不改视觉逐格规范）。

## 1. 现状问题（重构动机）

现行流水线经大学/中庸两轮实证，暴露六个结构性混乱点：

1. **两份正文来源并存且不一致**：P6 出具（`punctuated.json`/善本点校本.md）正文取 M2 `shanben-v2`（旧OCR原字+整页重OCR仲裁），M6 入库（`works/*-songben/text.yaml`）正文取视觉转写列文字（grid.json / grid-transcribe.json）。两份"善本正文"理论上可能冲突，靠人工比对兜底。
2. **同一书影"读字"重复三趟**：M2 整页重OCR（recollate）→ M3 列级（judge-grid）→ M3 逐格（grid-transcribe）。费用与不一致风险叠加。
3. **列级/逐格双路线并存**：M6 默认路线A（列级 grid.json），可选路线B（逐格转 grid 形状），职责边界模糊。
4. **对校发生在连续文本层（P3），与版面脱节**：orphan/相邻重叠/低分段只能给 `segId + regionId`，回书影核验成本高（quality-report 6 条问题定位难，正是本轮讨论起点）。
5. **标签/清洗分散多环节**：P1.5 区域分类（body/页眉/脚注/校记）、M3 经注判定（顶格/退格）、M6 章题切分，三处规则互不知晓。
6. **M2 互证未利用最准的视觉字**：逐格（覆校模型 qwen3.8-max，实测与基准完全一致）质量高于整页重OCR，但底本仲裁只用了后者。

## 2. 重构核心思想

**网格为基，参校挂格，标签分层，单一出口。**

- **基础层（真值骨架）**：`grid-transcribe.json` 逐格数据 `{col,row,char,start}`，规范不变。每格有唯一坐标 `(page,col,row)`，是所有后续层的挂载点。
- **参校层（overlay，旁挂不改规范）**：旧OCR 与现代点校本各自对齐到网格，产出"逐格参校意见"——`oldOcr`/`modern` 每格给出同/异/缺失。参校层**不能改格**；对网格 `char` 的修订走专门的 fixes 通道（带证据链，裁决后回写）。
- **标签层（overlay.labels）**：在网格上标 `role`：经 j / 注 z / 标题 title / 序 preface / 页眉 running-head / 页脚脚注 footnote / 尾题刊记 colophon / 跳过 skip。
- **出口层（单一出口派生）**：善本点校本（公开）、works/text.yaml（入库）、校勘记、质量报告全部从「基础层+overlay」派生，正文天然一致。

## 3. 探索实证（2026-08-17，双书四实验）

工具：`explore-grid-align.js`（锚点分段 + 归一化编辑对齐；归一=去标点符号+VARIANT_MAP 异体归一，**不改字**）。

| 实验 | 书 | 格数 | 一致率 | 替换 | 参校多 | 格多 |
|---|---|---:|---:|---:|---:|---:|
| 旧OCR→逐格（页级） | 大学 | 6,780 | **98.9%** | 19 | 14 | 42 |
| 旧OCR→逐格（页级） | 中庸 | 14,452 | **98.7%** | 46 | 49 | 90 |
| 现代本→逐格（全书锚分段） | 大学 | 6,780 | **95.6%** | 36 | 230 | 45 |
| 现代本→逐格（全书锚分段） | 中庸 | 14,452 | **94.4%** | 67 | 512 | 262 |

锚点法稳定：大学 44 锚 / 44 段、中庸 93 锚 / 93 段，无超长无锚段。

### 3.1 差异构成（全部可解释）

- **替换 ≈ 异体 + 真异文**：异体为主（宫/宮、污/汙、慎/愼、两/兩、絕/絶、歲/歳——需扩 VARIANT_MAP）；真异文如 大學 p5 間/聞、p7 止/至、p13 右傳之一章/右傳之二章、**p26 鳴鳩(格)/鳲鳩(现代)**——最后一条正是现行 quality-report seg383 低分段之谜的答案，格级对齐直接定位到 `p26 c8-5`。
- **旧OCR"旧多"**：旧OCR有字而逐格空格/漏字（大学 p10"昇居之長"、中庸 p7"晉府中庸傳"题记）——逐格疑漏列，回 G1 补验。
- **现代本"现代多"**：LaTeX 残留（`$^{ }$`）、页眉（"大學章句序""朱熹章句"重复出现）、校记（"司禮監本吴本有矣字""行遠升高…作升高行遠"）——**全部是 P1.5 清洗已分流的类别**，证明现代参校层必须先过预清洗再对齐。
- **"格多"**：○ 归一不对称（实验脚本两侧处理不一致，实施时统一）+ 章题/章首错位（中庸"右第X章"章题区 DP 错位，需章题锚专项）+ 大学 p12"又日新之不"（**格有、v2 无——校勘记 c4 修复争议的视觉证据**，参校层自动捕获）。

### 3.2 结论

1. 两个参校层对齐到网格**技术上完全可行**，一致率 94–99%，残余差异可归因、可机检。
2. 格级对齐把现行"句段级"问题（orphan/低分/重叠）**消解为逐格坐标**，定位即书影位置。
3. 每条"替换"就是一个候选校勘记条目，且自带善本页/列/行坐标——对校从文本层移到网格层后，P3 的结构性 blocker（孤儿/重叠/低分）失去存在土壤。

## 4. 重构后的流程（G 管线）

```
M0 装载（PDF/OCR 源，不变）
 │
G1 视觉逐格（基础层）        grid-transcribe 全量补齐（大学缺 p37-40、中庸缺 p77-78）
 │                            取代 recollate 整页重OCR + judge-grid 列级（三趟读字并一趟）
G2 参校对齐（overlay.variants）
 ├─ G2a 旧OCR → 逐格          页级对齐（~99%），每格记 oldOcr: 同|异|∅
 ├─ G2b 现代本 → 逐格         先复用 P1.5 清洗规则剥杂（页眉/脚注/校记/LaTeX），
 │                            再全书锚点分段对齐；每格记 modern: 同|异|∅
 │                            （差异只记录，不改格；fixes 走 G4 裁决）
G3 网格标签（overlay.labels）
 ├─ 版面规则：start 顶格=j / 退格=z（逐格自带，零成本）
 ├─ 结构规则：章题/尾题锚（右經一章、右傳之X章、右第X章、X章句序、畢+刊记）
 │            → section 边界 + title/preface/colophon
 ├─ 区域规则：版心/鱼尾空列、封面、末页刊记、现代本侧页眉脚注（G2b 已分流）
 └─ 参校佐证：章题判定用现代本结构（structure 强锚）交叉确认
G4 异文裁决（格级）           输入=overlay.variants 的"异"集合 → 现行 P4 diff 归类
 │                            （异体/真异文/ocr疑）+ P4.5 视觉复核（verifyChar 整页图）
 │                            + P5 四校书官裁决 → resolved 产出 fixes（改字通道）
G5 单一出口（基础层+overlay 派生）
 ├─ 善本点校本（公开）：网格+标签 → 连续文本 + 句读（P5b/P6 等价）
 ├─ works/<id>/text.yaml（入库）：网格+标签 → j/z blocks（M6 等价，路线A/B消失）
 ├─ 校勘记：G4 输出（格坐标化）
 └─ 质量报告：格级指标（参校覆盖率、未覆盖格清单、锚点覆盖率、fixes 未决数）
```

### 4.1 数据模型（overlay 旁挂，基础层规范零改动）

```jsonc
// collation/data/<书>/grid-overlay.json
{
  "base": { "file": "grid-transcribe.json", "sha256": "…" },   // 指纹锁基础层
  "variants": [   // G2 参校对齐结果（每非空格）
    { "page": 26, "col": 8, "row": 5, "grid": "鳴", "oldOcr": "鳴", "modern": "鳲" }
  ],
  "labels": [     // G3 标签
    { "page": 26, "col": 8, "row": 5, "role": "z" }            // j|z|title|preface|running-head|footnote|colophon|skip
  ],
  "sections": [ { "id": "zhuan2", "name": "傳之二章", "from": {…}, "to": {…} } ],
  "fixes": [      // G4 裁决后的改字通道（唯一允许改基础层 char 的路径）
    { "page": 12, "col": 7, "row": 3, "from": "曰", "to": "日", "evidence": "oldOcr=日; modern=日; verdict=…" }
  ]
}
```

## 5. 风险与开放问题

1. **逐格未全覆盖**：大学缺 p37–40、中庸缺 p77–78（非标准页：题跋/刊记）。G1 补跑成本 qwen3.8-max ≈ ¥0.46/页；亦可按《逐格还原》文档用 GPT-5 Terra 混合（¥0.02/页，需人工抽验）。
2. **现代本锚点依赖预清洗**：校记/页眉若混入流会污染锚点（中庸 ins 512 的主因）。G2b 必须先跑 P1.5 规则，且锚点提取需跳过校记邻域。
3. **章题区错位**（中庸"右第X章"）：需章题专项锚 + 章题格固定 label=title，禁止参与正文 DP。
4. **"只能改字"治理**：fixes 必须带证据链（参校源、视觉复核、裁决记录），人工确认后统一回写基础层；禁止参校层直改。
5. **异体归一表扩容**：本轮实证新增 宮/污/沒/愼/兩/絕/歲/寛/嘆 等待补 VARIANT_MAP（替换数将显著下降）。
6. **M2/shanben-v2 的历史定位**：建议保留为"旧OCR+整页重OCR互证快照"存档，不再演进；新作品直接走 G 管线。
