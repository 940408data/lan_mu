# 朱丝栏引擎方案（四库全书·文津阁写本）

> 缘起：2026-08-22 以《钦定四库全书·零本·子部·庄子注·卷一至二》清乾隆文津阁抄本（157 页）为据，抽样 32 页（`input_data/四库全书/samples/`），新增 `siku`（朱丝栏）引擎。分支 `engine/siku-zhusilan`（基于 `engine/shiji-manuscript`，复用纸张模块）。

### 1.2 版面形制
- 朱丝栏：栏框朱色双边（外粗内细），栏线朱色单线七道分八行。
- 半叶 8 行 × 行 21 字（大字单行）；注小字双行 × 21 字，随经而下（合栏）。
- 版心（栏外左侧）：上「钦定四库全书」、中书名「庄子注」（提要叶作「提要」）、下叶次（中文数字）。
- 天头极高（约 22%）、地脚约 11%；纸象牙色、洁净，微有黄斑。
- 避讳：玄→元（「大畅元风」），遵四库馆成法。

### 1.3 书法与精神
- 馆阁体楷书：匀整、圆润、乌黑（乌方光），一字如一，无一笔放纵——**盛世一统之秩序、朝廷编纂之庄严**。
- 与 songke（刻之秩序）/ manuscript（写之呼吸）鼎足：siku 是「**抄之庙堂**」——众手如一、朱栏为界、御览为印。

## 二、引擎设计（layout kind: `siku`）

### 2.1 数据模型（works/zhuangzi-zhu/）
- meta.yaml：`layout: siku`；`siku:{colsPerHalf:8, bigPerCol:21, subPerCol:21}`；`expect{chars,cols,leaves}`；`seed`；`division: 子`（部色：经绿/史红/子蓝/集灰）。
- text.yaml sections：提要 / 卷一 / 卷末。blocks 类型：
  `sk-head`（钦定四库全书）、`sk-class`（书名+类目）、`sk-sub`（提要）、`sk-title`（卷次）、`sk-authors`（衔名双小栏）、`sk-chapter`（篇题+随注）、`sk-officials`（衔名列）、`j`/`z`（经注）。
- seals.yaml：卷端大印「乾隆御览之宝」。
- book.yaml：封面（绢+题签）→ 黄签页 → 诸叶 → 卷末。

### 2.2 模型层 src/core/model/siku.js
- 专用排格（不借 songke 三版）：大字 21/行；注双行 21/行，随经合栏（本行余容不足 2 小字则新起行）。
- 特殊块各独占一行；section 起新叶（补空行至叶界）。
- 半叶两两配叶（右先左后）；版心叶次按 section 更始。
- expect 校验同 manuscript。

### 2.3 渲染层 src/render/html-siku.js
- 半叶（560×990 设计单位）：象牙纸（复用 `paperSvg`，轻老化：fox≤6、无渍蛀）→ 朱丝栏（双边框+七栏线，色 #b0492b）→ 版心条（三事竖排）→ 行字（大字 28px；小注双栏 15px）→ 朱点不施（四库本无句读点，守原貌）。
- 卷端叶叠大朱印（九叠意、opacity .82、multiply）。
- 封面：部色绢面 + 题签（墨栏双边、签条竖排）；黄签页：右下黄签二枚竖排。
- 整册导航复用 manuscript 之翻页 JS（左键下一叶）。
- 字体：馆阁体以 **霞鹜文楷 TC** 暂代（A 级），`faces.kai` 留槽待更匀整之楷。

### 2.4 三引擎鼎足（记入双引擎方案文档之续）
| | songke 刻 | manuscript 写 | siku 抄 |
|---|---|---|---|
| 主体 | 作坊众工 | 书家一人 | 馆臣众手如一 |
| 界 | 墨栏 | 无界 | 朱丝栏 |
| 气质 | 载道重器 | 庋藏珍玩 | 庙堂盛典 |

## 三、首作与测试
- 首作《庄子注》卷一至二（样本册）：提要全录 + 逍遥游开篇二叶余 + 卷末衔名。
- `validate --work=zhuangzi-zhu` 过闸；serve 预览与 s002/s006/s010 并排比对：朱栏八行/21 字/双行注/版心三事/题签/黄签/大印。

## 四、假设
- 陆德明音义小注从略（首版仅郭象注），后续可补；避讳字遵原书（元风）。
- 部色默认子部蓝灰绿；经史集三部色留参待用。
