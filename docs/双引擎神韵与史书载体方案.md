# 双引擎神韵与史书载体方案

> 缘起：2026-08-22 以新加坡国立大学藏《史记》传姜立纲抄本书影为据，新增 `manuscript`（明人写本）引擎。复刻既成，遂论 `manuscript` 与 `songke` 两引擎各自之神韵，并定史书（二十四史）之载体方略。本文为此美学与载体决策之定案文档。

## 一、两引擎各自的神韵

### manuscript 明人写本：一人之笔墨，百年之包浆

写本的精神气质，是「身体的、一次的、不可复得的」。

- **墨韵即呼吸**。台阁体楷方正沉劲，而逐字有蘸墨的浓淡节奏、微妙的错位与欹侧——字不是排出来的，是一个人写出来的。引擎以 `glyphMarks`（k 浓淡 / j 错位 / h 欹侧）复刻的正是这种「手写的身迹」：饱墨起笔、渐行渐淡、再蘸再书。
- **无界格即自由**。行疏字密、天头开阔，没有边栏行线的约束，行气贯通、疏朗从容。这是书写者的自信，也是写本区别于刻本的第一眼气质。
- **纸在叙事**。水渍的褐边、虫蛀的锐点、霉斑的晕散、扉叶的虫道、薄纸的透背、书口的叠层纸边、中缝的折叶阴影——每一处「不完美」都是时间的笔触。写本之美不在洁净，而在**包浆**：纸本身是第二作者。
- **整册即仪式**。靛灰布面、四眼线装、扉叶、褐签题跋、朱文钤印——书是一个被摩挲、被收藏、被题跋的「物」，藏着历代主人的目光。

一句话：**manuscript 是书斋的、私人的、温热的——「一人之笔迹，百年之包浆」。**

### songke 宋版善刻：一版之格律，千载之载道

刻本的精神气质，是「工艺的、规范的、可复得的」。

- **界格即秩序**。边栏、行线、版心、鱼尾、白口，半叶几行、行几字，皆有定式。字被网格庄严地托起，是印刷工艺的纪律之美。
- **经注即学统**。经大字单行、注小字双行，疏又随之——一层层注疏是千年学术的层累，版式本身就是经学的谱系。
- **刀法即克制**。宋体横轻竖重、起落有棱，是刀锋对笔意的转译；不追求一个人的温度，而追求一代工匠的精度。

一句话：**songke 是庙堂的、公共的、端严的——「一版之格律，千载之载道」。**

### 对照

| | songke 宋版善刻 | manuscript 明人写本 |
|---|---|---|
| 动作 | 刻 | 写 |
| 主体 | 作坊·众工 | 书家·一人 |
| 美核 | 秩序·规范·可复 | 呼吸·身迹·唯一 |
| 时间感 | 定式恒常 | 包浆流逝 |
| 视觉锚 | 界格·鱼尾·双行注 | 无界·朱点·水渍虫蛀 |
| 气质 | 载道之重器 | 庋藏之珍玩 |

### 工程镜像

二者在工程上亦互为镜像：`songke` 以 `meta.expect` 基准忠实于**版式之制**；`manuscript` 以种子化纸张（`src/core/paper.js`）忠实于**一册之态**。所忠不同，而「确定性复现」的纪律则一——同一 seed，HTML / JPG / PDF 三端输出永远一致。

## 二、史书载体论：写本承史，何以绝配

史书写的是**时间**，而写本的纸本身也是**时间**——水渍是某次雨漏，虫道是某段庋藏，包浆是百年的摩挲。别的载体是「容器装内容」，写本是「时间的物质化遇见时间的叙事」，两重时间在同一张纸上叠合。更有两个细节是天然的史学隐喻：

- **透背**：史文从纸背隐隐透出——历史本来就是正反两面写的，纸背亦有文章。
- **朱笔句读与钤印题跋**：句读是**读者**的时间，藏印是**流传**的时间。一部史书被一代代人点过、藏过、跋过，写本引擎恰好把这些层累都做成了一等公民。

于是史事、书迹、藏迹三重时间同纸叠合，史学的本质「传承」在版式里有了形体。以写本承史，不止是绝配，几乎是唯一能同时承载这三重时间的引擎。

## 三、二十四史载体方案：私修写本、官修刻本

若整部二十四史都用写本，会抹平史学史自身的一大分野。故定**双轨载体论**：

### 史学史的分野

- **前四史是「一人之笔」**。《史记》是「史家之绝唱，无韵之离骚」，《汉书》《后汉书》《三国志》亦皆私修、成一家之言——与写本「一人之笔墨」的气质完全同构。传姜立纲抄本《史记》更是实物佐证。
- **唐修《晋书》以降是「史馆之公器」**。官修众手、朝廷颁行，它的历史形态恰恰是**刻本**——明监本之南北监、毛氏汲古阁《十七史》、清武英殿《二十四史》。「二十四史」作为合刻概念，本身就是刻本文化定型的。

### 双轨映射

**私修诸史用 `manuscript`（庋藏写本），官修诸史用 `songke` 一系（庙堂刻本）**——载体的私/公，正对应史学的私修/官修。兰木现有双引擎恰好各自归位，不必新造。

### 落地建议

1. **系列叙事「一阁庋藏」**：二十四史以同一藏家的庋藏为框架，每史一册写本/刻本，各有藏印、题跋、纸色——系列感来自「同一藏家的不同藏品」，而非统一模板。
2. **包浆即元数据**：将 `ornaments.yaml` 的 `paperDecor{stain,holes,fox,trails}` 参数与「传世年代」挂钩——传得越古包浆越深：《史记》纸最苍、《明史》纸最净。「包浆就是时间」落成数据字段。
3. **名篇珍叶策展**：四千万字全录不现实，写本天然适合「名篇珍叶」——《项羽本纪》《报任安书》《班超传》等逐篇成叶，少而精，正合写本「珍玩」属性；`manuscript` 模型按 20×8 自动续叶，亦不妨碍后续全录。
4. **字体槽位**：长篇系列启动前，可寻一款更近台阁楷的 OFL 楷面登记入 `meta.faces`（`fontRole` 思路），霞鹜文楷 TC 暂代即可起步。

## 四、与现有代码的对应

| 文档概念 | 代码落点 |
|---|---|
| 无界格·行疏字密·题低二字 | `src/core/model/manuscript.js`（`manuscript.charsPerRow/rowsPerHalf/titleDrop`） |
| 墨韵呼吸 | `src/core/calligraphy.js` `glyphMarks`（k/j/h） |
| 纸在叙事·包浆 | `src/core/paper.js`（种子化 SVG：水渍/霉斑/虫蛀/虫道/帘纹/老化） |
| 透背·叠页·中缝 | `src/render/html-manuscript.js`（bleed 镜像层 / 书口叠层纸边 / 折叶阴影） |
| 整册仪式 | `works/<id>/book.yaml`（封面→扉叶→题跋→诸叶→末扉叶→后封面） |
| 经注学统·界格秩序 | `src/core/model/songke.js` + `src/render/html-songke.js` |
| 确定性复现 | 两引擎共用 `meta.seed` + `meta.expect` 校验纪律 |

## 附：结论

- 以写本承《史记》及前四史，是绝配；
- 以写本 + 刻本双轨承二十四史，是史学史的数字镜像——此为兰木双引擎体系的完成形态。
