# 宋版影刻直出引擎方案：逐格数据直渲作品页

> 分支：`engine/songke-facsimile`（worktree `.claude/worktrees/songke-facsimile`）
> 日期：2026-08-18。状态：V2（grid-transcribe.json 坐标直出，精校台渲染纪律）。
> 上游：`collation/` G 管线（G1 逐格 → G2/G3 overlay → G4 裁决 → fixes）。

## 1. 动机：text.yaml 中间层的信息损失

现行链路是「逐格数据 → G5 压平为 text.yaml（连续文本）→ songke 引擎**重排** → 作品页」。压平与重排丢掉的信息：

1. **坐标全丢**：页/列/行坐标在 text.yaml 中不存在，重排后的列界是算法近似。
2. **双行切分失真**：原刻注文双行的真实切点被压平，songke 按「双行均齐」算法重新猜切。
3. **空格消失**：敬空、阙字、章末余白在连续文本里无法表达。
4. **证据链断裂**：裁决 fixes 的 from/to/evidence 只剩一个最终字。
5. **页界丢失**：text.yaml 无页概念，叶次与原刻不再对应。

逐格数据（`grid-transcribe.json` + `grid-overlay.json`）天然是全真原刻列阵，直接渲染即得「影刻级」还原。

## 2. V1 复盘：转换层的三处失真（已废弃）

V1（提交 cc92ace）虽以逐格数据为源，但转换与渲染各丢一层，实证病灶：

| # | 病灶 | 位置 | 实害 |
|---|---|---|---|
| 1 | 全空列整列删除 | grid-to-work.js `if (!chars.replace(/\u3000/g,'')) continue` | p2 的 col9-16（左半叶整白）、p6 的 col3-8（中缝空白）消失 |
| 2 | cells 压成定长串 | grid-to-work.js 列×chars 串化 | 逐格坐标 (col,row) 隐没于串位置，数据不再是坐标 |
| 3 | 按数组长度切半 + z 列配对 | viewer `half=ceil(phys.length/2)`、pairCols | p2 八列被劈成「左右半叶各 4 列+版心居中」；相邻 z 列强扭成一个物理列 |

**V2 教训**：任何「转换时顺手重组」都是版面失真之源。坐标数据必须原样直达渲染层。

## 3. V2 核心决策

- **grid-transcribe.json 是唯一权威**：转换只做「cells 原样快照 + fixes 覆盖 + labels 旁挂」，不删空列、不压串、不配对、不拆半。
- **渲染 = 精校台坐标纪律 + 宋刻皮肤**（`grid-review.js` 实证的方案）：

```css
.sheet { display: grid; grid-template-columns: repeat(16, var(--u));
         grid-template-rows: repeat(15, var(--u)); direction: rtl; }
/* 每格显式 grid-row:row / grid-column:col（rtl 下 col1=最右），空位自然留白 */
```

一页一 sheet（16列×15行等宽格阵）：p2 的 col9-16 无 DOM 自然留白（左半叶整白），p6 中缝 col3-8 自然留白——**坐标即版面，无需任何拆分/配对逻辑**。j/title 列大字、z 列小字仅以字号区分。版心（鱼尾+书名+叶次）为 sheet 中央绝对定位竖条，不占格。
- **不被 songke 引擎代码限制**：model 薄化为「grid 直通 + stats」，无列阵化；分派仍走注册式 `MODELS['songke-facsimile']`，songke 本体零改动。

| 维度 | songke（重排引擎） | songke-facsimile V2（坐标直出） |
|---|---|---|
| 数据源 | text.yaml 连续文本（无坐标） | grid.yaml cells 三元组（坐标全真） |
| 排版 | typeset 算法重排切列 | CSS grid 显式定位，零重组 |
| 空白 | 无法表达 | 空 cell 无 DOM，自然留白 |
| 叶次 | 重排后新叶次 | 与原刻叶次一一对应 |
| 校勘层 | 无 | fixes 挂格，朱记+悬停证据链 |
| 适用 | 无逐格数据的通行本校录 | 有 G 管线逐格数据的善本还原 |

## 4. 数据流

```
collation/data/<书>/grid-transcribe.json   （基础层，永不改；pages[].cells[] = {col,row,char}）
collation/data/<书>/grid-overlay.json      （labels / sections / fixes）
        │
        ▼  collation/tools/grid-to-work.js <书> <新作品id> --write
works/<新作品id>/grid.yaml                  （cells 无损快照 + 证据链）
        │
        ▼  src/core/load.js（装载 grid.yaml）
src/core/model/songke-facsimile.js         （薄化直通，kind: 'songke-facsimile'）
        │
        ▼  src/render/html-songke-facsimile.js（壳 + payload + 字体栈 + T2S）
src/viewer/songke-facsimile.js             （浏览器端坐标渲染）
```

### 4.1 grid.yaml（V2 格式）

```yaml
work: 大学章句
base: { file: grid-transcribe.json, sha256: af85ff6a… }
layout: { cols: 16, rows: 15 }
labels:  [ { page: 2, col: 1, role: j }, … ]   # overlay.labels 原样
pages:
  - n: 2
    cells: [ [1,1,大], [1,2,學], … ]            # [col,row,char] 三元组，只含有字格
sections: […]                                    # 章节（目录/导航）
fixes: […]                                       # sub 已应用（cells 即裁决后字）+ insert 快照
```

- **空格/空列不存**：由 layout(cols×rows) 隐含，渲染层空位自然留白——p2 左半叶整白、p6 中缝空白全真。
- **sub 类 fixes**：导出时应用（cells 已是裁决后字），fix 条目保留证据链供校勘交互层。
- **insert 类 fixes**：默认不入版面（原刻本无此字），保留快照，渲染时栏外提示「参校本多出」。
- **cell.start（頂格/退格推断）不存**：顶格与否已由 row1 有无字表达，属冗余。

### 4.2 渲染规则

- 一葉 = grid 一页 = 一个 `.fsheet`：`display:grid; repeat(cols,var(--cw)) × repeat(rows,var(--u)); direction:rtl`。
  格为矩形：行高 `--u`（一字一行距）、列宽 `--cw = --u×1.40`（行宽，与 songke 同源——行气疏朗），版心轨 `--bx = --cw×.95`。
- 每有字格显式 `grid-row / grid-column` 定位（禁 grid-auto-flow——空格无 DOM 占位时防挤位错列，精校台实证纪律）。
- j/title 列大字（`.fcell.j`）、z 列小字（`.fcell.s`），等宽格内以字号别之。
- 版心：`.fbanxin` 独占中缝真实轨道（不遮两侧列），上下白口、单黑鱼尾、书名、原刻叶次、刻工（meta.facsimile.gong 轮值）。
- 栏线（界行）：逐**有字列**一条纵贯（`.crule` 与格同轨叠加），空列无栏线——p2 左半叶整白即无栏线，正是原刻空白叶面貌（逐格数据独有的全真）；右栏「界行」可关。
- 句读朱点：punctuated.json（P5b 点校产物）段末字映回格坐标成 `marks`，逐格施点（JV 十六式仿手批）；右栏施朱四式循环（经注并朱/惟经/惟注/白文）。映回容错：全书全局流（段跨页天然支持）+ 常见异体归一 + 顺推/全域两档搜（经注混排段序回流）+ 尾 8 字锚；大学 571 段命中 529，余 42 段散在各页不致整页无点。
- 视觉令牌与 songke.css 同源：纸色/墨色/朱色、纸纹噪点、四缘晕影、外粗内细匡郭、题签右栏（自动滑出唤回）、专注模式（全屏+字号二档）、下载（逐格数据 JSON 直出，PDF 摹刻二期）。

## 5. 与精校台的结合

精校台（`grid-review.js` → `精校台-网格.html`）与影刻直出共享同一渲染对象——逐格坐标矩阵——但服务两种角色：

| | 精校台 | 影刻作品页 |
|---|---|---|
| 读者 | 校勘者（私人） | 公众读者 |
| 疑问格 | 红框标注 + 裁决面板（改字操作） | 校勘朱记 + 悬停证据（只读展示） |
| 书影 | 并列对照（辅助裁决） | 不嵌（作品页保持纯粹） |
| 输出 | 裁决 JSON → fixes | grid.yaml → 作品 |

V2 已直接继承精校台的坐标渲染纪律（sheet grid + 显式定位 + rtl）；后续可抽公共 `src/viewer/grid-view.js` 供两者共用，消除双份实现（二期，先立后破）。
