> 日期：2026-08-17。适用范围：大学章句 / 中庸章句（G 管线 G1–G4 已落地 dev，分支 `engine/collation-grid-officer` 合入 e47501f）。
> 前置方案：[网格基流程重构方案](/网格基流程重构方案.md)（docs 同名，分支内）；实施验收：[网格基重构-双书实施验收与量化评价](/网格基重构-双书实施验收与量化评价.md)（docs 同名，分支内）。

## 1. 概述：G 管线数据链路

网格基流程以**视觉逐格**为唯一基础层，旧 OCR 与现代点校本都是参校，全部差异旁挂在 overlay 上；人工裁决经精校台产生，唯一改字通道是 `fixes`。

```
grid-transcribe.json（视觉逐格·基础层·规范不可改，已有数据，不重跑）
   │  G2 参校挂格（旧OCR页级对齐 + 儒藏本预清洗/锚分段对齐）
   │  G3 标签层（start→j/z 列规则 + 章题锚收束式 sections）
   ▼
grid-overlay.json（参校层 variants + 标签层 labels + sections + fixes）
   │  G4 校书官四议（officerOpinion + aggregate，LLM / mock 兜底）
   ▼
grid-officer.json（四官意见·私有，基础层指纹锁）
   │  精校台生成（每页竖排网格 + 疑问标注 + 点击裁决面板）
   ▼
精校台-网格.html（人工裁决入口·私有）
   │  导出裁决 JSON → grid-review-merge.js 合入
   ▼
overlay.fixes（唯一改字通道：sub 改字 / insert 补夺文）
```

**三条铁律**：
1. 基础层 `grid-transcribe.json` 永不直接修改；
2. 改字只能经「精校台裁决 → 合入 fixes」通道；
3. 参校层只记差异（variants），不改基础层。

## 3. 启动流程（5 步）

> 全部命令在仓库根 `d:\note\lan_mu` 下执行；`<书>` 取 `大学章句` 或 `中庸章句`。

### 步骤 1：参校挂格（G2/G3）

```powershell
node collation/tools/grid-overlay.js <书> --input-root=d:/note/lan_mu/input_data --write
```

- 默认 dry-run（只打印报告）；`--write` 才写入 `collation/data/<书>/grid-overlay.json`
- 报告含：G2a 旧OCR一致率、G2b 儒藏一致率、锚点统计、预清洗分类、G3 sections 列表
- 验收参考：一致率 ≥94%（实测大学 99.6%/98.9%、中庸 99.5%/98.9%；sections 大学 12 节、中庸 34 节）

### 步骤 2：校书官四议（G4）

```powershell
# mock 兜底（离线可用，立即出结果）
node collation/tools/grid-officer.js <书>

# 真实引擎（四官 LLM 审议，增量续跑）
$env:DASHSCOPE_API_KEY="sk-..." ; node collation/tools/grid-officer.js <书>
```

- 产出私有 `input_data/<书>/_derived/collation/grid-officer.json`（gitignored）
- 增量断点：按基础层指纹 + 条目 id 去重，可反复续跑不重复消耗
- 只审议 sub 类异文；extra/missing（衍/夺候选）不请四官，以书影为据

### 步骤 3：生成精校台

```powershell
node collation/tools/grid-review.js <书>
```

- 产出私有 `input_data/<书>/_derived/collation/output/精校台-网格.html`（单文件离线，双击即可打开）
- 自动内嵌步骤 2 的校书官意见（若已生成且指纹匹配）

### 步骤 4：人工裁决（浏览器）

1. 双击打开精校台 HTML；
2. 逐页浏览竖排版面，疑问格有红框标注；
3. 点击疑问格 → 面板显示：格字 / 旧OCR字 / 现代点校字 / 机器参考建议 / 校书官四议表 + 聚合结论；
4. 选择裁决：维持格字 · 从旧OCR · 从今本 · 自定义 · 存疑（可加备注）；
5. 夺文句在独立列表逐条裁决（补入 / 维持）；
6. 完成后点「导出裁决 JSON」保存（建议存 `input_data/<书>/_derived/collation/`）。

### 步骤 5：合入 fixes（唯一改字通道）

```powershell
node collation/tools/grid-review-merge.js <书> --file=精校裁决-<书>.json --write
```

- dry-run 默认；`--write` 生效
- 幂等：同坐标覆盖旧条目；基础层指纹不匹配则拒绝（需重跑步骤 1 后重新精校）
- `choice=keep-grid` 清除既有 fix；`defer` 留痕不入 fixes

## 4. 精校台使用说明

### 4.1 版面

- 每页 16×15 竖排网格，`direction:rtl` 列自右向左，**显式坐标定位**（`grid-row/grid-column`），与 `grid-transcribe.json` 的 (col,row) 逐格对应；空位留白不挤位
- 经（j）大字 / 注（z）小字 / 章题（title）底色；页头显示「第N页 · 列×行 · 疑问x 已裁y」

### 4.2 疑问标注体系

| 样式 | 含义 |
|---|---|
| 红框 | 字异（格字 ≠ 现代点校或旧OCR，sub 类） |
| 橙框 | 仅旧OCR 异（sub 类，现代本一致） |
| 虚线框 | 衍/幻觉候选（extra 类） |
| 紫点框 | 夺文锚点（missing 类，对应夺文句列表） |
| 绿框 | 已裁决 |

### 4.3 裁决面板

- 五选一：维持格字（keep-grid）/ 从旧OCR（oldocr）/ 从今本（modern）/ 自定义（custom）/ 存疑（defer）
- 校书官四议：官名 / 倾向 / 证据等级·置信 / 理由；聚合结论 `resolved`（建议 + 预填默认选择）或 `suspended`（暂拟 + 悬置原因，不代选）
- 保存后该格转绿框；裁决存浏览器 localStorage（`grid-review:<书>:<指纹>`），**换浏览器/清缓存会丢**，务必及时导出

### 4.4 导出与合入

导出 JSON 结构：`{ work, base, exportedAt, decisions[], runs[] }`；`decisions` 单字裁决（含 page/col/row/grid/oldOcr/modern/choice/custom/note），`runs` 夺文句裁决。合入见步骤 5。
