### 工程记录

- **strIdx 索引断裂 bug**（已修）：格串 STRIP 归一后与 flat 格数组索引错位，导致 sub 坐标漂移。修复为显式 `strIdx` 映射（○ 等符号格不进串、留在 flat，坐标永远可回溯）。教训：**任何"归一串"都必须携带到原坐标的映射**。

### 新方案的诚实短板

1. **G4 未实施**：fixes 改字通道空，"只能改字"治理尚无裁决入口（P4 diff/P4.5 视觉/P5 校书官可平移，但需适配格级输入）。
2. **基础层单源视觉**：逐格虽实测最准，幻觉风险仍在——两参校层正是对冲手段，但 fixes 前不可直改。
3. **重叠区未自动归并**：大学 p4/p25 两处重叠在格串中仍在（新旧体系都未消），需 G4 或人工一次性处理（处理后 G2 重跑即可全局收敛）。
4. **中庸儒藏章题不齐**：硬锚失效降级软锚（质量未受影响，但应回查儒藏 OCR 章题行）。
5. **迁移成本**：S3 剩余（校书官接格级输入）、S5（质量闸/文档/旧管线下线）未做。

## 4. 结论

1. **方向正确且已实证**：网格基在双书上全部关键指标超过旧方案，且旧方案的三类结构性缺陷（双正文源、入库残缺、伪异文噪声）在新体系下消失或显式化。
2. **最大增益是"定位即书影"**：每条异文自带 `page/col/row`，人工核验从"查两跳文件"变为"直接看书影"，这是校勘生产力质的改善。
3. **旧方案的价值应平移而非抛弃**：P4 异文归类、P4.5 视觉复核、P5 四校书官裁决、法理双本隔离设计全部可挂到 G4/G5，无返工。
4. **建议**：按 S3（G4 裁决接格级）→ S5（质量闸+文档）推进；两处重叠区先行人工处理并验证 G2 重跑收敛；中庸儒藏章题行回查。
