## 1. S0 环境与材料考察

### 1.1 底本身份核验（方案 R1 消解）

- 起因：当涂 OCR p10 首行「欽定四庫全書」，初判疑为四库抄本配补。
- 核验：Grep 全书 445 页仅 2 处（p10 首行 / p267 正文中间）；浏览器实拍 p267 影像正文「死生有命富貴在天→命稟於有生之初」连续无此词；p10 页顶亦无页眉；三 PDF（论语 p10/p267、大学 p8）Producer 均 MuPDF 1.28.2 同批。
- **结论：底本为宋本当涂郡斋刊递修本（与大学/中庸同源）；「欽定四庫全書」为 LLM OCR 幻觉插入（四库套语先验），非影像实有。**
- 教训（记入 skill 坑表）：**OCR 文本 ≠ 影像事实，底本层判断必须实拍核验；单页样本不得推广全书。**

## 4. S3 G2/G3 · 全量 overlay

首轮全量结果：G2a 99.1% ✓、G2b 96.7%（但**格多 221 异常**）、sections 仅 1（缺 pian2）。

### 4.1 坑：篇题锚异体失配（爲/為）

- 现象：sections 只有 pian1:學而第一，缺 爲政第二。
- 根因：格串 p28 为「**為**政第二」（qwen3.8 输出正体，VARIANT_MAP 归一方向 爲→為），而 deriveAnchors 生成的正则用登记原刻字形「爲政」——正则未经 canon，异体失配。
- 修复：deriveAnchors 对每个篇名生成「原字形｜归一字形」双写 alternation（登记仍可写原刻）；复跑 sections 2 个 ✓，硬锚 1→2。
- 附带现象：sections.name 取匹配文本，故为「為政第二」（正体）；原刻字形保留属精校 fixes 阶段职责。

### 4.2 坑：影印本重复叶（p40/p41）

- 现象：G2b extra 221 中 **p41 独占 190**——对齐偏移信号。
- 核验：逐格文本 p40 与 p41 逐字全同（仅 c7 取舎/取舍 一字之差）；OCR md 两页全同（仅标点差）；PDF 哈希不同（两次导出）。结论：**影印本同一版面重复拍摄**。
- 机制：新增 dupPage 登记（layout.json specialPages kind=dupPage + dupOf）+ loadBaseGrid 装载时跳过副本（不改基础层文件，铁律不破）。G2a 页级对齐自洽（两边同含重复），G2b/G5 受益。
- 修复后：G2b extra 221→13，一致率 96.7%→**99.4%**。
