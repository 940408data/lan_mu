# 首页方案 v2：签条切换与卷影四屏

> 2026-08-13。承接 `docs/建站理念和首页方案.md`（纲领）与 v1 落地（`engine/home-wenzhi`，已并 dev：四时主视觉、四书次视觉、部类页签居后）。
> v1 主/次视觉层级获认可；用户指认三处待优化，并给出新方向。本文档为 v2 方案，**结构二选一待用户定夺后实施**。

## 一、v1 遗留问题与 users 新方向

**问题（用户原话归纳）**

1. **部类页签与四书涵泳重复**——儒家页签 = 学庸论孟瓷青书影，与四书板块同源同形，「没有意义」。
2. **深层藏缺出口**——纲领定位书库「只渡有缘人、不主动推」，但 v1 首页把部类编选整段摆在页面里，既重复又冲淡了「藏」的分层。
3. **专题推荐缺席**——v1 撤销专题卡后，`/topics/` 入口只剩板块题小链；将来高濂《四时幽赏录》配套等专题内容需要展位。

**用户新方向**

- 主页 = 四时 + 四书 + 专题推荐；原主页的部类编选退为**底部链接**（深层藏 → 书库）。
- 主/次视觉的结构待选：**左右签条切换**（点「四时」显示四时的四幅卷轴局部截图；点「四书」显示原首页的四书方案）或**上下直陈**。

## 二、两案共通调整（已定方向，不再议）

1. **部类页签从首页移除**。
2. **虚拟典籍并入书库**：佛家（金刚/维摩诘/法华）、道家（道德/南华/冲虚）在选题以 virt tome「敬请期待」入 `/shuku/` 对应部类 section——书库 = 真全帙 + 在选题，深层藏名副其实。检索索引数据源由 `TABS` 改为新配置（索引行为不变，虚拟书仍可检）。
3. **首页底部加「入書庫 · 全帙一览」链接**（深层藏出口）。
4. **专题推荐区回归**：两卡（四時幽賞 / 四書涵泳）链 `/topics/` 页；恢复 v1 删去的 `COPY.topicHead` 与 `.topic` 卡样式（git 可捞）。
5. **检索行保留**于 masthead 下（门户功能义务；若求极简可议，见 §八待决 3）。
6. topnav / masthead / FOOT / 专题页 / 目录叶 / 作品页不动。

## 三、A 案：左右签条切换（推荐）

```
┌──────────────────────────────────────────┐
│ topnav ｜ masthead ｜ seek                │
│ ┌────┬───────────────────────────────┐   │
│ │四時 │  四扇卷影屏（默认呈现）         │   │
│ │幽賞 │  春   夏   秋   冬             │   │
│ │────│  ▌▌  ▌▌  ▌▌  ▌▌  各链作品页   │   │
│ │四書 │  （点击左签 → 换瓷青书影四部）  │   │
│ │涵泳 │                               │   │
│ └────┴───────────────────────────────┘   │
│ 专题推荐（两卡 → /topics/）               │
│ 入書庫 · 全帙一览 →                       │
│ FOOT                                     │
└──────────────────────────────────────────┘
```

- **左栏签条**：两条竖排大签（楷、宽字距），选中者朱色左缘 + 提亮。即原部类页签交互的竖排化——「完全参考原来的那种方案」。
- **右栏 · 四时（默认）**：四扇卷影屏——四部手卷各截卷首竖条（见 §五），自右而左春夏秋冬，每扇缀季节朱字 + 题名，整扇即链接进作品页。
- **右栏 · 四书**：瓷青书影四部（`bookTome` 现成输出，带精校/初校图标与底本小字，链 `/books/<id>/` 目录叶）——即用户所谓「原来首页的四书方案」。备选：保留 v1 竖排条目（见 §八待决 2）。
- **无 JS 退路**：两面板直陈 = 自然退为 B 案（渐进增强，JS 仅做显隐）。比现页签「无 JS 只见首部」更友好。
- **窄屏**（≤820px，沿用现有断点）：签条退为顶部横排，内容区在下。
- **气质**：一屏聚焦；文露质藏，点击而进阶——正合「由文入质、自愿进阶、绝不强施」。

## 四、B 案：上下直陈（稳健低配）

- 即 v1 骨架：上 = 四时（书影**升级为四扇卷影屏**），下 = 四书（竖排条目或书影），板块题 + 题辞领起，间距沿用 2.8rem 节奏。
- 上下节奏：四时占视觉重（卷影屏高约 16rem），四书纤一度；先文后质一页尽览。
- 无交互、零 JS 依赖、改造成本最低；但「藏」意弱于 A，且四书与卷影同页并置，形制须错开（卷影 vs 条目/书影）方不闷。

## 五、卷影四屏管线（两案共享的新工件，重点设计）

**原料核实（2026-08-13）**：`image.js` 出图产物为 `dist/works/<id>/<Base>-<Tag>.jpg|png`（按字面多份，如 lanting 有 Jing/Song/Xingkai 三份）。**现状仅 lanting 有出图产物**；dushanjing/chibifu/huxinting 须先 `--only=jpg` 补齐。

- **源**：作品整卷 **PNG**（无损存档份），按作品主字面选对应 `<Base>-<Tag>.png`。
- **裁切**：自**右缘**（手卷右起读，卷首在右：题字 + 印章所在）取宽约 560px × 全高竖条。`pngjs` 读、`jpeg-js` 写（`image.js` 现有依赖，无新增）。
- **产物**：`dist/assets/topics/<id>.jpg`（四部各一，预计 30–60KB）。
- **构建接线**：全量 build 末尾（全部作品出图后、站点页生成前）新增「专题卷影」步骤；单作品 `--only=jpg` 后若属四时则同步更新该片。
- **dev 占位**：`serve.js` 渲染时检测卷影缺失 → 占位块（瓷青渐变 + 竖排题名 + 季字），dev 免构建可预览；静态构建缺图则告警并落占位。
- **视觉**：四扇并排（flex 四等分），`height:16rem`、`object-fit:cover`、1px 暗边 + 微投影；hover 微亮上浮（与 tome 呼应而更克制）；扇底缀季节朱字 + 题名小字；窄屏退 2×2。
- **何以卷影优于书影作主视觉**：书影 =「藏书」语言（与书库同形），卷影 =「展卷」语言——主视觉本义是接引赏玩，展卷见字见印、直入其美；且与四书板块（书影或条目）天然形制分层，文质不点自明。

## 六、两案对比与推荐

| | A 左右签条（推荐） | B 上下直陈 |
|---|---|---|
| 先文后质 | 文露质藏，点击进阶 | 文先质后，一页尽览 |
| 接引 | 一屏一事，聚焦 | 内容地图，总览 |
| JS 依赖 | 增强式（无 JS 即 B） | 无 |
| 改造成本 | 签条交互 + 左栏响应式 | 最小 |

推荐 A：「不抢占主视觉、不压迫新人、自愿进阶」的最贴形制；且其无 JS 退路天然包含 B，进可攻退可守。若求稳求快，B 亦可立行。
