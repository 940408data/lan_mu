# 个人文史书法古籍网站 · 建站核心思想与整体架构方案

## 一、网站核心总立意（方向性纲领，随实践校准）

### 核心主旨：文质彬彬，然后君子

本纲领非一经立言永不改之戒律，而是**方向性纲领**——立意既定，落地细节随实践与认知校准（见第六节准则 1「先实后文」）。第二节即旧→新思路的迭代复盘，可见立意本就在演进；第七节则对照现状代码盘点，使纲领不脱离底子。

本站一切排版、内容、入口设计，**全部围绕「文、质二元体系」展开**，完全贴合儒家正统思想，同时适配现代大众阅读习惯，不强行施教、不居高临下、不劝退新人。

1. **文（外在风华、接引众生）—— 四时幽赏**
对应天地风月、文人情志、书法审美、四时闲趣。
以德之华示人，先以温润、优美、松弛的古典审美接引普通人，是大众进入传统文化的**第一道温柔入口**。

2. **质（内在根基、修身立本）—— 四书涵泳**
对应圣贤义理、修身养心、朱子治学、心性底色。
是人愿意深入传统文化后，向内扎根、沉淀本心的**进阶修行路径**。

3. 核心心法（孔子施教逻辑，全站底层逻辑）
古之贤人、孔门弟子，**皆先观夫子温良风雅之文，后入圣贤修德之质**。
不先授厚重经义，先示人天地风华，**由文入质、由浅入深、自愿进阶、绝不强施**。
恪守：己所不欲，勿施于人。不以自身多年治学门槛，绑架普通访客审美与学习节奏。

## 二、新旧建站思路迭代复盘

### 1. 初始旧思路（存在核心弊端）

- 首页直接展示：儒、释、道三大经典库 + 经史子集完整典籍体系
- 底层逻辑：遵从古人治学顺序「先经、次史、再次子、最后集」，以典籍大本为网站核心
- **致命问题**：现代人与传统文化断层极深，经藏、道藏、佛藏门槛极高，99.99% 访客一眼劝退，网站彻底沦为极小众圈内站，失去接引大众、传播风雅的初心。

### 2. 最终定稿新思路（平衡本心与大众、兼顾专业与亲民）

**对外迎客：以「文质彬彬」为首页核心门面**
**对内守本：以「儒释道经史子集」为后台精神大本**

做到两全：

1. 不妥协自己的核心信仰与古籍、书法、儒释道治学体系；
2. 不劝退普通大众，保留新人入门通道，温柔接引传统文化爱好者。

### 3. 独立页面：图书馆（网站精神大本、后院宝库）

**原旧版首页整体迁移至此，不作为迎客门面**
仅放置于导航栏（「書庫」入口），供深度爱好者、同好自主探寻，不主动推送、不强迫浏览。

图书馆内部完整架构（恪守传统目录学正统）——**远期愿景，非近期**：

- 儒家：经史子集全体系、十三经、四书古本、历代儒典
- 佛家：各类佛藏经典
- 道家：道藏及道家核心典籍

定位：**网站最深层的治学根基，只渡有缘人**，普通访客可终身不点开，依然完整体验网站核心内容。

> 【远景标注 · 2026-08-13】三藏全体系为远期愿景。现状真书：儒家四书四部（大学/中庸/论语/孟子）、佛家心经一部（余金刚/维摩诘/法华为虚拟占位「敬请期待」）、道家真书为零（道德/南华/冲虚为虚拟占位）。离「三藏全体系」差数个数量级，纲领画远景，如实标注远期，不使人误以为建站即配齐。

### 4. 附记页面（延后上线、内容积累后更新）

不初期亮相、不开局立义，**先有实、后立言**。

内容包含：

- 全站文质彬彬的完整设计立意
- 「四时为文、四书为质」的深层逻辑

避免开局空讲道理、有义无实，完全贴合儒家「先行后言」思想。

## 四、远期可选：双模式首页（不列近期）

> 【降级 · 2026-08-13】本节原拟近期落地全站「风物 / 典籍」模式切换开关，自称「技术可落地、理念最适配」。但：现状单一首页（四时幽赏接引）+ 书库深藏（资深用户点入大库），已完成「普通用户赏风物、资深用户进大库」的分层，无需模式开关；且首页尚在迭代（精校图标等），模式开关工程量不小、需求未经验证。依第六节准则 1「先实后文，先做后说」，本节**降为远期可选，不列近期**。

### 需求（远期）

区分普通访客与资深文史用户，兼顾小白体验与专业同好的使用习惯。

### 设想方案（远期探讨，非近期落地）

1. **默认模式：风物模式（大众迎客首页）**
所有匿名访客、新用户默认进入，四时幽赏为主、温柔低门槛。

2. **自选模式：典籍模式（专业大本首页）**
增加全站切换开关：【风物模式 / 典籍模式】

- 普通用户：保持风物模式，轻松赏文、观字、品四时
- 资深文史同好、高级爱好者：**自主手动切换**为典籍首页，直接进入经史子集、儒释道大本体系

### 核心优势（贴合建站本心）

1. 不通过系统判定用户等级，**尊重所有人的自主选择**
2. 不违背「己所不欲勿施于人」，不强行切换页面造成困扰
3. 兼顾 SEO、链接分享、浏览器适配，无技术 bug
4. 同一网站，可浅玩、可深研，兼容所有层级传统文化爱好者

## 五、全站层级逻辑闭环（终极总结）

1. **表层（迎客）**：四时风月、千古美文、书法雅韵 → 渡普通大众
2. **中层（修身）**：四书涵泳、朱子义理、本心沉淀 → 渡进阶爱好者
3. **深层（立本）**：儒释道三藏、经史子集典籍 → 渡资深同好、治学之人

4. 双层文质闭环

- **网站大层面**：四时幽赏 = 文（外在风华），四书涵泳 = 质（内在修身）
- **专题小层面**：高濂闲赏 = 文（浅表风物），四篇千古至文 = 质（四时精神）

## 六、长期运营核心准则

1. **先实后文，先做后说**：积累足量内容、作品、解读后，再公布立意体系，不做空谈网站
2. **由文入质，循序渐进**：永远以审美接引，不以经义劝退
3. **兼容并蓄，不偏不执**：保留儒释道全部核心典籍，只藏不推，守己本心、随人志愿
4. **温柔传道，绝不强施**：允许所有人只爱风月、不研经义，各取所需、各得其所
5. **守正统、顺时代**：内核恪守传统目录学、朱子理学、古典美学，外观适配现代大众审美

## 七、附：现状底子与技术债盘点（对照代码，2026-08-13）

为免纲领脱离底子，此节对照现状代码盘点，供执行参照。评审指原稿「未对着 `home.js` 校对、漏两个核心入口、混写已建/待建」——本节正之。

### 现状底子（`src/site/` + `tools/`）

- **门户配置** `home.js`：`NAV`（幽蘭第五 / 書庫 / 校書官）、`TABS`（儒家經典 / 佛家 / 道家 三页签）、`TOPICS`（四時幽賞 / 四書，四時已置前）、`BOOK_META`（点校类别 + 底本）、`COPY`（固定文案）
- **渲染** `render.js`：六函数 `renderHome` / `renderShuku` / `renderTopic` / `renderComingSoon` / `renderJiaoshu` / `renderToc`，产出自包含 HTML
- **聚合** `aggregate.js`：按 `meta.book` 块归并书列表，单卷书标 `standalone` 直链作品页
- **静态构建** `build.js`：调 aggregate + render 全套写 `dist/`，并做 A 级小字库子集化（`dist/assets/fonts/`）
- **双轨生成**：`tools/gen-index.js` + 全量 build 末尾产出静态文件（生产）；`tools/serve.js` 动态渲染同式页面（dev 免重建）

|---|---|---|
| `/` 首页 | `renderHome` | 真实门户口（检索 + 部类页签 + 专题推荐） |

4. **高濂配套**：见第三节.2.1，新增内容待补
