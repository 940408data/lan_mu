# 人工精校台设计 · 暨两套校勘方案对比

> 参照 `/root/ops_dianjiao`（Python 包 `guji_collator`，七阶段 S0–S7）的人工精校台（review.py），为兰木 `collation/` 管线设计 P7 人工精校环节；并系统对比两方案优劣、列出可借鉴清单。
> 本文是 `docs/古籍校勘流水线.md` §5 的补充设计，审批后与 ①–⑤ 一并施工。

## 1. 两方案对比

### 1.1 对照表

| 维度 | ops_dianjiao（guji_collator） | 兰木（collation/） |
|---|---|---|
| 栈 | Python 3.10+ 零依赖 | Node CommonJS |
| 校勘学形式化 | **深**：陈垣校法四则→角色限权、证据四级、双因子加权投票、底本优先 β=0.15、悬置三规则 | 浅：四官并行 + ≥3 同采 & 均信≥0.6 粗规则 |
| 异文分类 | **9 类**（通假/避讳/形近/脱/衍/倒/实质/异体/句读），避讳作断代证据显式标注 | 5 类（异体/真异文/ocr疑/夺/衍）+ 夺衍簇（P4.5） |
| 归一化 | CNF 可逆索引（index_map），裁断必落底本原字形 | VARIANT_MAP 仅匹配用、输出原刻字形（同理念，形式化较弱） |
| 对齐 | 文本级 LCS 锚 + NW（古籍代价函数：通假0.25/避讳0.35/形近0.45/gap0.8） | 句锚点+编辑距离，**页/列溯源**、剥书题、朱子章句强锚 |
| OCR/视觉 | 演示引擎+桩（协议要求每字 bbox）；三方置信对数几率融合；漫漶→□不猜字 | **真视觉管线已实证**：两路互证纠旧 OCR 40 处、初校/覆校分级、思考开关 5.7× |
| 版面结构 | 无 | **版面结构先行**（layoutProbe→grid 判经注 91.7%、可复原排版进引擎）——独有 |
| 句读版权闸 | **RuleSegmenter 独立断句 + Jaccard>0.92 告警** | 句读借现代本句末标点投影——**有隐患，待补** |
| 裁决体例 | **四库体例校勘记文**（「今仍底本之舊，不改。」） | 表格 + 理由 |
| 人工精校 | **单文件离线 HTML 精校台**：键盘流、localStorage、decisions.json 回灌 apply | flags.yaml 手工回写——薄弱，待升级 |
| 测试 | **pytest 契约锁死**（总数/分类/Jaccard/避讳断言） | validate(expect) + verify(幽兰逐字节)，校勘无契约测试 |
| 产物形态 | 公开本+参校本（文本） | 双本 + **songke 引擎三态呈现**（HTML/JPG/PDF）+ 站点 |
| 实证规模 | demo 11 条锁死；大学真实语料接入中 | 大学 49 真异文 × 4 官真 LLM 已裁（29决/20悬） |

### 1.2 各自优点

**ops_dianjiao 优点**
1. 校勘学纪律写进代码：限权合议庭（解缙「绝不杜撰书证」、纪昀「不引新证只裁断」）防理校泛滥——清儒「文义较顺改字」大忌的制度化解。
2. 证据分级 × 角色权重 × 置信度 的加权裁决，底本优先 β 偏置，三条悬置规则（τ=0.55 / δ=0.18 / **无硬证据改正文必悬**），OCR 置信 <0.75 联动悬置。
3. 句读独立生成 + Jaccard 告警，从技术上执行「公开本不抄今本标点」的版权隔离。
4. 精校台让人工只处理机器不敢定的部分，每条 15 秒内可决；候选字投影正体、底本原字原样——防简体字经人工之手落入公开本。
5. 测试即契约，回归基线确定性。

**兰木优点**
1. **版面结构先行**——视觉只答网格与顶退格，经注由规则客观推导；对方无版面概念，产出仅 flat 文本。
2. 真视觉管线（互证/覆校/分级/思考开关）已在真实善本上纠正旧 OCR 40 处；对方 OCR 层是演示桩。
3. 真实规模 LLM 校书官已跑通（大学 49 条）；对方生产 LLM 客户端是替换件，实证为 demo 规模。
4. 引擎一体化：善本底直接进 songke 出三态，站点集成。
5. 对齐带页/列溯源 + 书题剥离 + 强锚，适配真实古籍 OCR 噪声。

### 1.3 各自缺点

**ops_dianjiao 缺点**：视觉层未落地（无真 OCR/无版面）；实证规模小；文本级对齐无页码溯源；无双态呈现；工程冗余（双副本静默分叉之坑，其 CLAUDE.md 自认）。
**兰木缺点**：裁决形式化不足（无证据分级/加权/β/悬置三规则）；异文分类粗（无通假/避讳/倒文）；**句读借今本、无版权闸**；校勘记无体例文；人工精校只有 flags.yaml 手工回写；无契约测试。

## 2. 可借鉴清单（按优先级）

### P0 · 随本轮重构（①②③④）一并施工
1. **人工精校台**（本文 §3 设计）——flags.yaml 的 UI 化 + decisions.json 回灌。
2. **悬置三规则 + 证据分级 + 底本优先 β**：officer.js aggregate 升级——意见加 `grade`（確證/旁證/推測/無證，系数 1.0/0.7/0.4/0.15），加权投票，底本候选 ×1.15；悬置条件：首选占比 <0.55、首选次选差 <0.18、**改正文而四官皆无確證/旁證**。
3. **限权硬约束进 officers/*.md**：解缙绝不杜撰书证（无据即言无据）、纪昀不引新证只裁断、刘向唯版本不改字。

### P1 · 随 ⑤ 中庸或就近施工
4. **异文分类细化**：diff.js 增加 通假/倒文 判定与避讳标注（避讳是断代证据，显式标注不静默还原）；校勘记每条生成**四库体例句**（「X，今本作Y。…今仍底本之舊，不改。」）。
5. **□ 规则**：视觉/OCR 不识处输出 □ 占位、绝不猜字（recollate/build-v2 遵循，与「视觉多字舍」保守原则一致）。

### P2 · 架构级增强（中期，另立项）
6. **RuleSegmenter 独立句读 + Jaccard>0.92 告警**——公开善本点校本的版权闸。当前句读借今本句末标点投影，需自研保守文言断句器替换，告警入 validate。
7. **bbox 级书影定位**：视觉复核回原图精确框位（现整页+上下文定位已够用，列为增强）。
8. **契约测试**：固定 fixture 断言异文分类与悬置数（补 validate/verify 之外的校勘回归）。

### 不借鉴
- Python 栈与演示 OCR 引擎（我们已有真实视觉管线）；其 NW 对齐算法本身（我们句锚点+溯源更强）——但其**代价函数的分类思想**（形近≠脱+衍）已由 P4.5 簇级「换」类型等价承接。

## 3. 人工精校台设计（P7 升级）

### 3.1 定位
P7 由「flags.yaml 手工回写」升级为正式环节：**精校台 HTML（人决）→ decisions.json（回灌）→ 重出定本**。flags.yaml 保留为纯文本兜底。原则照 ops 版：**人工只处理机器不敢定的部分，每条 15 秒内可决**。

### 3.2 产物与数据流
```
export.js 生成 output/精校台.html（单文件、零依赖、可离线）
  数据源：verdicts.json(suspended) + clusters-verify.json(真异文簇待裁) + 已决项(折叠页签供抽查)
人工：键盘流裁断 → localStorage 暂存 → 导出 decisions.json
run.js <书> --step=apply --decisions=<path>
  → 回写 verdicts.json（verdict:'human'，adopt 按 choice，保留机器意见原文——可推翻、可追溯）
  → 自动重跑 export 吸收（善本点校本/现代本/校勘记/精校台同步更新）
```

### 3.3 案例卡（每条内容）
- 头：编号 / 类型（真异文·夺·衍·换）/ 位置（善本页·现代本页）/ 悬置原因（承接悬置三规则，明列触发哪条）。
- 上下文：底本 …〔字〕…，今本作〔…〕；簇级给短语对照。
- 四官意见：姓名 / 方法 / **证据等级** / 置信 / 理由（含线索）。
- 机器裁断与风险说明。
- 候选按钮：**底本原字（原样）** / 今本字（**投影正体**——防简体落公开本）/ 两存 / 删（衍文专用）。
- 按语框：人工按语写入校勘记。

### 3.4 键盘流
`J/K` 移动 · `1-9` 选读法 · `V` 展开双侧书影 · `E` 导出 decisions.json。
页签：待覆核（默认）/ 已决 / 全部；进度计数常显。

### 3.5 对 ops 版的增强
1. **V 键书影**：每案内嵌双侧书影裁剪条（善本页+现代本页各裁上下文行带，base64 jpeg 小图，单文件仍离线）。裁断看原刻是人工最核心的需求，ops 版纯文本做不到；默认折叠保 15 秒流速。
2. **簇级夺/衍入台**：ops 版无此概念；我们 P4.5 核验为真的簇与字级真异文同席裁断。
3. **悬置原因明列**：触发 τ/δ/无硬证据哪条规则直接显示，人工知其所疑。

### 3.6 不变式（测试契约，随施工锁定）
- 待覆核数 = suspended 数 − 已回灌人工决策数；
- 任何简体候选不得出现在公开本可选读法中；
- 回灌后校勘记该条标「人工裁定」+ 按语，机器四官原文保留；
- 精校台.html 单文件无外部请求（离线可开）。
