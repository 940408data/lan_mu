# 史记·姜立纲本 逐格校勘实施记录

## 项目概况

- **底本**：史记·传姜立纲抄本（新加坡国立大学藏），明人写本
- **引擎**：manuscript（明人写本引擎），非 songke（宋刻引擎）
- **范围**：先完成前三卷（五帝本纪、夏本纪、殷本纪），共 33 页
- **方法**：G 管线（网格基校勘），G1 视觉逐格 → G2/G3 参校 → G4 四官 → G5 出口

## 数据结构适配

### 问题
史记数据目录结构与现有管线不兼容：
- 现有：`input_data/<书>/<ocrDir>/page_*.md`（平铺）或 `input_data/<书>/<卷>/<ocrDir>/page_*.md`（分卷）
- 史记：`input_data/史记_姜立纲本/史记整理目录/史记_姜立纲本ocr/<卷>/page_*.md`（嵌套 + 卷在 ocrDir 内）

### 解决方案
1. **`io.js` 新增 `pagesRoot` 字段**：edition 配置中可指定自定义根目录，覆盖 `INPUT_DATA/bookDir`
2. **`listPages` 双模式扫描**：
   - 模式 1（史记）：`<base>/<ocrDir>/<卷目录>/page_*.md`
   - 模式 2（论语/孟子）：`<base>/<卷目录>/<ocrDir>/page_*.md`
3. **worktree `INPUT_DATA` 回退**：worktree 下自动向上查找主仓库的 `input_data`

### 修改文件
- `collation/src/io.js`：pagesRoot 支持 + 双模式卷扫描 + worktree INPUT_DATA 回退
- `collation/tools/grid-transcribe.js`：传递 pagesRoot 到 pagePdfPath
- `collation/tools/build-v2-lite.js`：传递 pagesRoot 到 listPages
- `collation/config/editions.yaml`：shiji-jiang edition 添加 pagesRoot/ocrDir/pdfDir

## PDF 结构分析

- **每 PDF 页 = 一个跨页（spread）**，尺寸 1080×1008
- **左半叶**：有文字（8 列 × ~20 行），朱笔句读
- **右半叶**：空白（仅印章/老化痕迹）
- **页码映射**：OCR 页码全局连续，五帝本纪 6-17，夏本纪 18-28，殷本纪 29-38
- **渲染策略**：裁切左半叶（文字区），每 PDF 页 → 1 张 PNG（1080×2016 @2x）
