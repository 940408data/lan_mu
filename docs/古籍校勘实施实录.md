# 古籍校勘系统实施实录

> AI 古籍校勘子系统（`collation/`）从 0 到《大学章句》端到端走通的完整过程、核心方法论与经验教训。
> 配套：`collation/DESIGN.md`（系统设计）、`.claude/skills/guji-jiaokan/SKILL.md`（可复用 skill）、`docs/校勘异文讨论.md`、`docs/校勘优化方案.md`、`docs/古籍校勘推广指南.md`（后续怎么做）。

## 0. 提要

以**公开善本**（当涂郡斋刊递修本，南宋，国图藏）为底本、**现代点校本**（儒藏精华编）为对校本，经 OCR → 视觉互证 → 版面结构判定 → 对校 → 校书官 → 双本出具，产出可进兰木 songke 引擎的善本点校本。《大学章句》已端到端走通（`works/daxue-songben` 构建通过）。

**最重要的一条方法论**：**版面结构先行（grid-first）**——不让视觉直接猜经注（实测准确率仅 43.5%），而先抽样总结该书版面网格（当涂本 16列×15行、每格一字、顶格为经/退格为注），再由规则客观推导经注（核验 91.7%）。

## 1. 核心方法论（按重要性排序）

### 1.1 版面结构先行（grid-first）——本系统之基石

**教训**：最初让视觉模型直接判"这列是经还是注"，准确率仅 **43.5%**（模型把小字注文当大字经文），且同页两次判定结果不一（不稳定）。

**正确做法**（用户指正后确立）：
1. **版面抽样**（`layoutProbe`）：视觉 Agent 看几页善本，只总结**版面物理结构**——几列几行、每格一字还是双行夹注、每列起始顶格/退格、版心鱼尾书题位置。当涂本实测：**16列×15行（整叶两半叶各8栏）、每格一字、无双行夹注、顶格为经/退一格为注**、朱色句读点、○分节。
2. **经注规则推导**：顶格=经、退格=注（当涂本规则；他书或仅经/经注/经注疏，因书而异）。
3. **网格转写**（`gridTranscribe` / 列级 `gridColumns`）：每页按网格输出，**每个字落在其格**（col×row + 该列起始）。一鱼两吃：① 由顶格/退格客观判经注；② 网格数据供兰木引擎**严格复原古本排版**。
4. **核验**（`verify-jz.js`）：若有现成经注结构（兰木 works），只作 **ground truth 核验**视觉判定准确率；**不可反过来依赖它**（否则失去通用性）。

实测：全量 27 页准确率 **91.7%**（误判多为 2 字短列，核验基准自身的子串匹配对短列不可靠，实际更高）。

### 1.2 两路互证（不单一依赖视觉）

用户指正：不能断言"视觉 OCR 优于旧 OCR"。正确做法：
- 视觉重 OCR（`ocrPage`，关思考快）与旧 OCR **逐字比对**（`recollate.js`）→ 一致采信；
- 相异处规则仲裁（`build-v2.js`：视觉缺字采旧、多字舍、异体归一采善本古字形）；
- 真疑难覆校（`verify-v2.js`，看善本扫描确认实印何字）。
- 实测：纠正旧 OCR 误读 **40 处**（曰/日、丁/子、慘/僉、償/僨、母/毋…），均附字形依据（conf 0.9–0.99）。

### 1.3 初校 / 覆校分级 + 思考开关

两视觉角色，**名固定、底层模型可迭代**（`config/vision.yaml`）：

| 角色 | 底层模型 | 触发 |
|---|---|---|
| **初校** | qwen3.7-plus | 默认先跑（快/省） |
| **覆校** | qwen3.8-max | 初校置信 < 阈值(0.7) 时升级 |

**思考开关按任务**（实测对齐 `/root/guji_ocr` 脚本）：
- 关思考（`enable_thinking:false`）快 **5.7×**（经注判定 266s→46s）——适合**纯 OCR 照录**（看图抄字）。
- 开思考保精度——适合**版面判定/单字辨形/网格转写**（需看图推理）。

### 1.4 校书官（多智能体考据）

四官（刘向·本校源流 / 解缙·群籍旁证 / 戴震·音韵训诂 / 纪昀·折中定谳），画像在 `collation/officers/`，Node LLM 与 Claude Agent 共用同一份。对真学术异文各陈意见、陈列、出结论 resolved 或悬置 suspended（暂拟+线索）。**从理不从众**。

实测（大学 49 条真异文全量，qwen3.7-plus）：resolved 29 / suspended 20；意见引《广韵》反切、《经典释文》、《礼记》郑注、《太平御览》等他校。跨作品分歧（脩/修 大学 4/4 存古 resolved、中庸 2v2 suspended）正是"可悬置"的体现。

### 1.5 双本分流（法理）

- **善本点校本**（公开）：善本为底 + 原创点校，公有领域，可公开传播。
- **现代本**（自用）：现代点校本为底，有整理者著作权，**不入 dist、不外传**。
- 两线物理隔离：善本点校本只引善本之字。

### 1.6 边界三层（必须守住）

| 层 | 答什么 | 谁做 |
|---|---|---|
| 客观层 | 实印何字 / 版面网格结构 | 视觉模型 |
| 倾向层 | 该用哪个字（学术倾向+理据） | 校书官 |
| 裁决层 | 真学术争议（版本源流、石经他本） | **人**（如大学 v82 二/一、中庸 v278 脩/修） |

## 3. 关键经验教训（坑与对策）

| 坑 | 现象 | 对策 |
|---|---|---|
| 直接让视觉猜经注 | 准确率仅 43.5% | **版面结构先行**（抽样→规则→网格→核验） |
| 关思考判版面 | 快但变糙、conf 虚高 | 版面/网格任务**开思考**；纯 OCR 才关思考 |
| 视觉漏字 | 视觉缺字 125（关思考漏） | 互证时**缺字采旧** OCR |
| CJK-Ext-B astral 字 | sbNorm/sbToks 错位 1 格，全段误判异体 | normChar 对未映射 astral 字归一为单码元占位 |
| 页中书题 | 现代本鱼尾书题粘入正文→假夺 | 对齐预处理**剥书题行** |
| 校书官全量串行无保存 | 68min 无果 | adjudicate **增量保存+断点续传+条间并行** |
| qwen3.8-max 校书官 | 开思考太慢 | 校书官初校用 **qwen3.7-plus**；疑难升覆校 |
| bash 内嵌 `$(cat key)` | 触发分类器超时 | 脚本 `resolveApiKey` 自读 `~/.bashrc` |
| 书末题跋页 | 刻工落款页视觉识别差 | 人工处理或单独对待 |
| 善本「母」「毋」混用 | p18 实印毋、p27 六处实印母 | 底本忠实善本实印，校勘另议，不混入底本 |
