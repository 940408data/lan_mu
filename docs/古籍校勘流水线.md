# 古籍校勘流水线（流程与产物总览）

> 本文是 AI 古籍校勘子系统（`collation/`）的**全流程总览**：从最初的输入开始，每一步做什么、产物是什么、谁消费。
> 当前流程以 **M2 新底本为下游唯一善本来源**，并用 SHA-256 指纹防止旧网格、旧对齐和旧校勘记混入新底本。大学 M2 覆校已清零并完成一轮后续重跑；中庸仍有 68 处待覆校。两书在后续质量闸未清零前只能作为 `draft` 审阅。
> 配套：`collation/DESIGN.md`（设计原点）、`docs/古籍校勘实施实录.md`（大学实施过程与方法论）、`docs/古籍校勘推广指南.md`（推广操作）、`docs/人工精校台设计.md`（P7 精校台与两方案对比）、`.claude/skills/guji-jiaokan/SKILL.md`（可复用技能）。

## 0. 一图总览

```
起始输入（§1）
  │
  ▼
P0 装载 io.js ──────────────→ 内存 Edition 对象（善本/现代本页行）
  │
  ▼
M0 版面抽样 layout-probe.js ─→ layout.json（列×行/格字制/顶退格规则/抽样页，落盘可复审）
  │
  ▼
M2 互证干净底本（仅善本侧；下游硬前置）
  M2a recollate.js ─────────→ recollate-<起>-<止>.json（视觉重OCR+逐字互证）
  M2b build-v2.js ──────────→ shanben-v2.json + pending-verify.json
  M2c verify-v2.js ─────────→ 直改回填 shanben-v2.json（终态唯一）+ verify-report.json
  M2 Gate ──────────────────→ 记录 shanben-v2 SHA-256；pending>0 只能 draft，禁止发布
  │
  ▼
M3 版面判定经注（只读当前 M2 新底本/指纹）
  judge-grid.js ────────────→ grid.json（页×列×{顶/退格,文字}+M2 hash）
  verify-jz.js ─────────────→ 判定准确率（借既有 works 作 ground truth，只核验不依赖）
  build-songke.js ──────────→ output/善本点校本-分栏.md（经注分栏）
  │
  ▼
P1.5 双本清洗 cleanup.js ───→ clean/{shanben-clean,cleanup-report}.json + 私有现代本正文
P3 对齐 align.js ───────────→ 私有 aligned.json（仅清洗正文流，带页/区域/hash 溯源）
  ▼
P4 对校 diff.js ────────────→ diffs.json（字级：异体/真异文/ocr疑）+ clusters.json（簇级夺/衍/换原生归并）
  ▼
P4.5 簇核验 cluster.js ─────→ clusters-verify.json（规则归类 + 双侧视觉四分类）
  │    善本底本误 → apply-basefix.js 回修 shanben-v2 → 重跑 P3 起（结论按内容键迁移，收敛即止）
  ▼
P5 校书官 officer.js ───────→ verdicts.json（真异文+ocr疑+核验为真的簇；证据分级加权+β+悬置三规则）
  ▼
P6 出具 export.js ──────────→ 公开 output/{善本点校本,校勘记}.md + quality-report/punctuated；
                              私有 output/{现代本,精校台}.md/html + flags.yaml
  ▼
P7 人工精校台（V键书影/键盘流）→ decisions.json → --step=apply 回灌 → 重出定本
  │
  ▼
M6 进引擎 build-works.js ───→ works/<新id>/ 四件套（校验 M2/grid 指纹）→ npm run build 验证
```

**串联入口**：`node collation/tools/pipeline.js <书名> --pages=起止` 会检查 M2、写入 P1.5 清洗产物、按页重跑 M3，再执行经注分栏与 `run.js --step=all`。不传 `--pages` 时不会偷偷复用与当前 M2 不匹配的旧 `grid.json`；下游仍可生成草稿，但质量报告必须保留 blocker。

## 2. 逐阶段详解

### P0 装载 — `src/io.js`
- **做什么**：读 editions.yaml + 两本 OCR 页 → 内存 Edition 对象 `{id, role, level, pages:[{n, lines, raw, isCover}]}`；登记 PDF 页数。
- **产物**：无落盘（内存）。封面页自动标记 isCover。

### M0 版面抽样 — `tools/layout-probe.js`
- **做什么**：视觉抽样 3–5 页善本（默认前/中/后），只总结**版面物理结构**：几列几行、每格一字还是双行夹注、顶格/退格规则、版心鱼尾书题位置。**每书必做，每书不同**。
- **产物**：`data/<书>/layout.json`（落盘：网格/规则/抽样页/probe 原文），judge-grid 默认读它（--cols/--rows 可覆盖）。
- **质量闸**：抽样结论须能解释正文的全部列起始形态。实测：大学、中庸同为当涂本 16列×15行、每格一字、顶格经/退格注。

### M2 互证干净底本（三工具一循环，仅善本侧；M2 之后的唯一善本底本）
- **M2a `tools/recollate.js`**：渲染善本页 → 视觉重 OCR（关思考，快 5.7×）→ 与旧 OCR 逐字编辑距离比对 → `recollate-<起>-<止>.json`（每页 agree 一致率、diffs、visText）。**闸：平均一致率 ≥90%**，过低查版面/OCR 质量。大学实测 92.9%。
- **M2b `tools/build-v2.js`**：两路对齐后规则仲裁（一致采信 / 视觉缺字采旧 / 视觉多字舍 / 异体存善本原刻字形 / 真异→暂采旧+列待覆校）→ `shanben-v2.json` + `pending-verify.json`。**对齐用归一字、输出用原刻字形**——善本古异体不丢。
- **M2c `tools/verify-v2.js`**：pending 按页分组渲染扫描，verifyChars 批量问「实印何字」（初校开思考，conf<0.7 升覆校）→ **直改回填 `shanben-v2.json`（终态唯一）** + `verify-report.json` 留痕；已处理条目从 `pending-verify.json` 移出，失败/未处理条目保留以便分批续跑。
- **M2 Gate（硬前置）**：`src/base.js` 只允许读取 `data/<书>/shanben-v2.json`，缺失即报错，禁止静默回退旧 OCR。下游同时记录 `source`、`sha256`、`pendingVerify`；`pendingVerify>0` 时可以继续定位问题和生成草稿，但质量状态固定为 `draft`，不得宣称已定稿。
- **底本变化即失效**：M2 覆校或 P4.5 `apply-basefix.js` 改写 `shanben-v2.json` 后，必须重跑 M3（网格）、P1.5、P3、P4、P4.5、P5、P6；旧 `grid.json` 若 hash 不一致会被清空/拒绝，旧校勘记与 M6 作品不得继续沿用。

### M3 版面判定经注（版面结构先行，输入锁定 M2）
- **M3a `tools/judge-grid.js`**：逐页 gridColumns（列级：起始顶格/退格 + 列文字）→ 规则判经注（顶格=经 j、退格=注 z）→ `grid.json`。文件写入 `base.file=shanben-v2.json` 和 `base.sha256`；当前 M2 变化时旧页判定不复用。断点续传、并行、开思考。
- **M3b `tools/verify-jz.js`**：以既有 works 的 text.yaml 为 ground truth 核验判定准确率（大学 91.7%）。**只核验、不反哺**（否则失去通用性）。
- **M3c `tools/build-songke.js`**：grid.json → 经注分栏 `output/善本点校本-分栏.md`（大学 129–134 blocks）。

### P3 对齐 — `src/align.js`
- **做什么**：**只读 M2 `shanben-v2.json` 经 P1.5 清洗后的善本正文**，与同样清洗过的现代本正文进行句锚点 + 编辑距离对齐。异体表 VARIANT_MAP **仅用于匹配归一，不改正文**；剥页中书题/页眉/校记/脚注等版面残留；朱子章句强锚（右傳之/右經一章/右第X章）。
- **产物**：`aligned.json`（段级：segId/score/orphan/现代句/现代页/善本串）。`--step=align` 单跑。

### P4 对校 — `src/diff.js`
- **做什么**：对齐段平坦化为两级异文。**字级**（v 编号）：异体（归一合、形异，登记不裁）/ 真异文（两本各通）/ ocr疑。**簇级**（c 编号，原生归并）：同段内相邻（间隔 ≤2 同字）夺/衍合成短语级簇——夺簇/衍簇/换簇（措辞异）/ orphan 整段。
- **产物**：`diffs.json` + `clusters.json`。按当前 M2 新底本重跑：大学为字级 100（真异文 31 / 异体 69）+ 簇 21；中庸为字级 333（真异文 91 / 异体 242）+ 簇 60。数量会随 M2 覆校和底本回修变化，不能与旧底本报告混用。

### P4.5 簇核验 — `src/cluster.js`（verify 步骤）
- **做什么**：逐簇定谳。**规则类**不动视觉：书题/页眉残字、牌记题跋页（按书登记起页）、现代本自带校记/音注脚注（原脱/未詳/去聲…）。**其余双侧视觉核验**：善本页+现代本页同呈一图call，按锚点定位、如实照录两侧实印，四分类——现代OCR误 / 善本底本误 / 真异文 / 书题牌记。初校→覆校路由，增量保存断点续传；每条结果写入当前 `baseSha256`，旧底本核验不会迁移。
- **回路**：善本底本误 → `tools/apply-basefix.js` 回修 shanben-v2（全锚定位；删除可短语回退；orphan 用核验录得的「善本前邻 6 字」定位 + **近邻守卫**防短句误补）→ 重跑 P3 起，核验结论按内容键自动迁移，收敛即止。大学实证：回修 10 处、簇 47→33。
- **产物**：`clusters-verify.json` + `basefix-log.json`（永久修复留档）。

### P5 校书官 — `src/officer.js`
- **做什么**：对**真异文 + ocr疑 + 核验为真的簇**逐条：四官并行各陈意见（带证据等级 grade）→ 加权聚合。**证据四级**（確證1.0/旁證0.7/推測0.4/無證0.15）×置信 = 得分；**底本优先** shanben×1.15；**悬置三规则**：首选占比<0.55 / 首选次选差<0.18 / 弃善本从他本而无確證旁證——居其一即悬置。旧裁决按内容键迁移不重跑。
- **产物**：`verdicts.json`。裁决必须引用当前 M2 hash；大学旧裁决已按内容键迁移，新的全链裁决仍以 P4.5 收敛后重跑为准。

### P6/P7 出具与人工 — `src/export.js` + `src/review.js`
- **产物**：公开 `output/善本点校本.md`、`output/校勘记.md`、`quality-report.json`、`punctuated.json`；私有 `_derived/collation/output/现代本.md`、`精校台.html`、`flags.yaml` 及对齐/异文/裁决 JSON。现代本连续文本不进入公开目录。
- **P7 精校台**：默认只列悬置条（已决折叠抽查）；键盘流 J/K 移动、1 采善本/2 采现代本/3 两存、**V 展开双侧书影**（低清页图内嵌，裁断看原刻）、E 导出 decisions.json → `run.js <书> --step=apply --decisions=<路径>` 回灌（verdict:human，机器意见原文保留可推翻）→ 自动重出定本。

### M6 进引擎 — `tools/build-works.js`
- **做什么**：grid.json → `works/<新id>/` 四件套（text.yaml 经注分栏 + meta 借 --base 模板 + seals/ornaments）。善本底独立新作品，不动通行本。
- **验证**：`npm run build -- --work=<新id> --only=html`。大学产物 `works/daxue-songben` 已过。
