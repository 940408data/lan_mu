# AI 古籍校勘（双轨对校）

把一部古籍的**公开善本**（底本）与**现代点校本**（对校本）经多智能体校勘，产出两份点校文本。实证：《大学章句》《中庸章句》（当涂郡斋刊递修本 vs 儒藏精华编）。代码在 `collation/`，设计见 `collation/DESIGN.md`，方法论讨论见 `docs/校勘异文讨论.md`、`docs/校勘优化方案.md`。

## 核心方法论：版面结构先行（grid-first）

**最重要、最易错的一步。** 不要让视觉模型直接"猜"某段是经还是注——实测此法准确率仅 43.5%（不可靠）。
**每本古籍版面不同**，必须先派视觉 Agent 抽样总结该书版面结构，再推导经注规则：

1. **版面抽样**（`layoutProbe`）：视觉 Agent 看几页善本，总结版面网格——几列几行、每格一字还是双行夹注、每列起始顶格/退格、版心鱼尾书题。
   - 例·当涂郡本：**16 列 × 15 行**（整叶两半叶各 8 栏）、**每格一字、无双行夹注**、顶格为经/退一格为注、朱色句读点、○ 分节、鱼尾书题在书口边缘。
2. **经注规则推导**：结合版面结构 + 常识/检索，定该书的经注规则（顶格=经、退格=注，因书而异）。
3. **网格转写**（`gridTranscribe`）：每页按网格输出，**每个字落在其格**（col×row + 该列起始）。一鱼两吃：① 由顶格/退格客观判经注；② 网格数据供兰木引擎**严格复原古本排版**。
4. **核验**（`verify-jz.js`）：若有现成经注结构（如兰木 works），只作 **ground truth 核验**视觉判定的准确率（判读方法效果）；**不可反过来依赖它**（否则失去通用性）。

实测：当涂本 page_0008 网格转写 240 格，规则判经注与兰木结构**完全一致**（vs 直接猜 43.5%）。

## 两路互证原则（不单一依赖视觉）

视觉模型（初校 qwen3.7-plus）读图有误差，**必须坚持互证**：
- 视觉重 OCR（`ocrPage`，关思考快）与旧 OCR 逐字比对（`recollate.js`）→ 一致采信；
- 相异处规则仲裁（`build-v2.js`：视觉缺字采旧、多字舍、异体归一）；
- 真疑难覆校（`verify-v2.js`，看善本扫描确认实印何字）——实测纠正旧 OCR 误读 40 处（曰/日、丁/子、慘/僉…），均附字形依据。

## 视觉模型两角色（config/vision.yaml，名固定、底层可迭代）

| 角色 | 底层模型 | 触发 |
|---|---|---|
| **初校** | qwen3.7-plus | 默认先跑（快/省） |
| **覆校** | qwen3.8-max | 初校置信 < 阈值时升级 |

- **思考开关按任务**：纯 OCR 照录关思考（快 5.7×）；版面判定/单字辨形/网格转写开思考（保精度）。
- key 走 env `DASHSCOPE_API_KEY`（逗号分隔多 key 轮询），**不入仓**。

## 流水线（七阶段）

```
P0 装载(io) → P1 OCR(旧OCR/视觉重OCR) → P2 互证仲裁干净底本(recollate/build-v2/verify-v2)
→ P2.5 版面结构先行(layoutProbe/gridTranscribe) → P3 对齐(align) → P4 对校(diff)
→ P5 校书官(officer) → P6 双本出具(export) → P7 人工复核(flags)
```

## 对校与校书官

- **对齐**（`align.js`）：句锚点+编辑距离，异体归一（`VARIANT_MAP`）、剥页中书题/内联校记、朱子章句强锚。**异体表只用于对齐归一，不改正文（正文存善本原刻字形）。**
- **对校**（`diff.js`）：异文分类——异体/真异文/ocr疑/夺/衍。**注意：夺/衍多为版式噪音（页中书题、题跋落款、回文错位），非真异文。**
- **校书官**（`officers/`：刘向/解缙/戴震/纪昀）：对真学术异文各陈意见、陈列、出结论 resolved 或悬置 suspended（暂拟+线索）。**从理不从众**。Node LLM 与 Claude Agent 共用同一份画像。

## 双本出具（法理分流）

- **善本点校本**（公开）：善本为底 + 点校 + 校勘夹注。公开善本+原创点校，可公开传播。
- **现代本**（自用）：现代本为底 + 全部校书官意见。有整理者著作权，**不入 dist、不外传**。
- 两线物理隔离：善本点校本只引善本之字。

## 边界（必须守住）

- 视觉模型只答"**实印何字 / 版面网格结构**"（读图）→ 客观层。
- 校书官给"**学术倾向 + 理据**"（考据）→ 倾向层。
- **真学术争议（如大学 v82 二/一、中庸 v278 脩/修）归人**（需核他本/石经），模型不强行定论 → 人工层。

## 用法

```bash
# 需 API（设 DASHSCOPE_API_KEY，逗号分隔多 key）：
node collation/tools/recollate.js <书> --pages=1-40 --conc=3   # 视觉重OCR+互证
node collation/tools/build-v2.js <书> --in=recollate-1-40.json # 规则仲裁→干净底本
node collation/tools/verify-v2.js <书> --conc=3                # 覆校仲裁真疑难
node collation/tools/judge-jz.js <书> --pages=8-36 --conc=2    # 版面判定（或用 gridTranscribe）
node collation/tools/verify-jz.js <workId> --jz=...            # 兰木结构核验准确率
node collation/run.js <书>                                     # 全链（对校+校书官+出本）

# 无 key 走 mock 兜底（全链可跑，产出基线）
node collation/run.js <书>
```

## 关键经验（坑）

- **关思考快但糙**：版面判定/网格转写务必开思考；纯 OCR 照录才关思考。
- **dpi ≥150**：网格/大小字判定需清晰图；太小会误判。
- **大图调用慢**：逐格转写 240 格/页约数分钟，用并行 + 多 key + 断点续传。
- **书末题跋页**（刻工落款/衔名）视觉识别差，宜人工处理。
- **善本「母」「毋」混用**等：干净底本忠实善本实印，"该用哪个字"的校勘判断另议，不混入底本。
